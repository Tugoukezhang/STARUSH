# 巡演现场的店灯、收工车和屋顶

`props-master.png` 是本项目 2026-11-25 用 GPT 生成的透明道具原画。四格依次是收工器材车、试听店耳机灯、咖啡亭杯灯、唱片店灯箱。导出器裁掉透明外边，把灯的实际脚座放回统一的画框。器材车与卷起的横幅叠在原来的港口棚屋网格内。未点亮和已上色状态保持同一物件、方向和轮廓。

`lights-master.png` 是同期生成的第二张原画。左侧帆灯为单枚青色镜片，右侧帆灯是双枚琥珀色镜片。屋顶校音台画成带音叉、双表头和旋钮的实际设备。

灰色与彩色屋顶底稿、装卸门底稿均保存自本项目本轮改动前的正式资源。屋顶导出保留原尺寸、大板缝与两边的风化纹理，中央走位和校音处逐渐减少斑点。装卸门在原门扇上增加铰链轴、把手和开缝标线。

用带 Pillow、NumPy 的 Python 运行 `python 01-美术/chapter-landmarks/export.py` 可重导十一张运行图。可传一个替代输出目录复核。输入另用到正式目录中的 `harbor-cohesion-20261009/shed.webp` 与其去色版本，供收工车和既有建筑对齐。
