# 公演手绘界面原稿

本目录保留了本轮用 GPT 出图的五张原始画稿。角色立绘沿用负责人已确认的三张原画。所有可变文字、数字、锁定状态和键盘焦点都由游戏绘制，换语言和改变字号时仍可读。

| 原稿 | 可单独替换的区域 | 游戏用途 |
| --- | --- | --- |
| nav-original.png | 左上场记板、右上话筒、左下巡演地图、右下器材箱 | 四个底栏入口 |
| tickets-original.png | 从上至下为黄绿演出票、浅纸票、深墨票 | 确认、次操作和深底操作的文字底面 |
| speaker-original.png | 透明底音箱贴纸 | 公演大厅的插画 |
| items-original.png | 第一行从左到右为声波、节奏、镜头、雨线。第二行使用回声、翡翠、纸叶三格 | 七件配件各自的插画卡底，与实物图独立 |
| rooms-original.png | 左上化妆间、右上器材间、左下档案室、右下排练场 | 模块场景及封面 |

修改原稿后，在此目录运行 `bash export.sh`。脚本需要 ImageMagick，把同一构图按游戏用到的位置裁开、缩小并写为 WebP。四个导航图标保留既有运行路径，其余位于 `game/public/art/printroom/`。

背包的回响风铃、回响书签直接使用已确认的绿、蓝角色兵装原图。导出脚本另存 256×256 透明 PNG 供背包缩略格使用；角色和装备详情继续加载 1254×1254 原图。
