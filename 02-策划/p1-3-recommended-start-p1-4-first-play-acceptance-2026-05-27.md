## P0 必须

### 1. 2 波内玩家分别学会什么

| 波次 | 玩家看到什么 | 玩家学会什么 | 最小通过标准 |
|---|---|---|---|
| WAVE 1/2 | 少量低压敌人进入，角色自动射击。屏幕出现移动提示。 | 拖动移动；角色会自动攻击最近敌人；本局目标是清掉当前波。 | 玩家能移动角色，看到自动射击命中敌人，并完成第一波。 |
| WAVE 2/2 | 出现更明显的颜色/形态提示，敌人数量仍少于正式关。 | 切色会改变弹幕反馈；切形态会改变攻击手感；积累应援可触发 C 位或 Encore 高潮。 | 玩家至少完成一次切色、一次切形态，并看到 C 位或 Encore 其中一个高潮反馈。 |

旧口径中的“3 波教学”不再作为 Stage 1 验收标准。首局仍以 3 分钟为体验上限，但实际战斗节奏按 2 波压缩。

### 2. 拖动移动、切色、切形态的最小提示文案

| 机制 | 出现时机 | 最小提示文案 | 文案要求 |
|---|---|---|---|
| 拖动移动 | WAVE 1/2 开始 3 秒内 | 拖动屏幕移动，弹幕会自动攻击。 | 不讲摇杆系统，不讲高级操作。 |
| 自动射击 | WAVE 1/2 首次命中后 | 靠近敌人，自动应援弹幕会命中目标。 | 让玩家知道不用手动瞄准。 |
| 切色 | WAVE 2/2 开始 5 秒内 | 点这里切换应援色，看弹幕效果变化。 | 不一次解释五色全规则。 |
| 切形态 | WAVE 2/2 中段 | 点这里切换形态，改变攻击方式。 | 不讲养成、解锁、数值成长。 |

提示形式建议：短气泡 + 按钮高亮。每条提示最多显示 2-3 秒，不打断战斗。

### 4. C 位或 Encore 是否必须保底，以及最小验收标准

必须保底至少一个。P0 建议保底 **C 位**，Encore 可作为 P1 增强或随机触发。

原因：

- C 位来自应援值累积，更适合两波内稳定触发。
- Encore 需要弱点/灼烧等条件，首局如果强行教学会增加理解负担。
- 玩家第一局必须看到一次“舞台高潮”，否则 STARUSH 的差异化记忆点不足。

最小验收标准：

| 项目 | 标准 |
|---|---|
| 触发时间 | 最晚在 WAVE 2/2 结束前触发。 |
| 触发方式 | 正常积累不足时，允许首局教学补足应援值。 |
| 视觉反馈 | 至少出现 C 位或 Encore 明确大反馈，持续 1.5 秒以上。 |
| 战斗反馈 | 触发后玩家感到变强，例如射速/伤害提升、清场加快、敌人明显被压制。 |
| 结算反馈 | 胜利提示中可显示“本局触发：C 位”或“本局触发：Encore”。 |

判定：如果第一局清关但没有出现 C 位或 Encore，P0 不通过。

## P1 可选

1. 如果 WAVE 2/2 中玩家没有主动切色，可在 5 秒后再次轻闪切色按钮。
2. 如果 WAVE 2/2 中玩家没有主动切形态，可在精英敌出现时再次轻闪形态按钮。
3. 胜利提示可追加一行“你打出了 C 位高潮”，但不做长教程。
4. Encore 若自然触发，可保留；但不要求首局同时触发 C 位和 Encore。
