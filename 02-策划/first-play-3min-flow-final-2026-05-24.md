# STARUSH Phase 1 首玩 3 分钟流程最终版

> 日期：2026-05-24
> 阶段：Phase 1 / First Play Polish Pass
> 交付对象：制作人 / 运营 / 原型执行团队
> 范围限制：只做首玩流程；不扩 GDD；不设计抽卡、商店、社交、长期养成；不做复杂章节地图；不做菜单教学。

---

## 目标

- 新玩家 60 秒内从标题进入第一场战斗。
- 3 分钟内看懂移动、自动射击、颜色切换、形态切换。
- 第一局至少看到一次安可或 C 位高潮。
- 胜利/失败都清楚知道下一步。

---

## P0 必须做

### 默认首玩配置

- 默认推荐角色：绯樱。
- 默认推荐形态：输出型。
- 推荐路径：标题页 → 推荐出战 → 第一舞台 → 战斗。
- 首玩期间不进入角色库、不进入复杂章节地图、不进入养成页。

### 0-180 秒流程

| 时间 | 玩家看到什么 | 玩家学会什么 | 必须触发什么反馈 |
|---|---|---|---|
| 0-30 秒 | 标题页只突出一个主按钮：开始公演。点击后弹出推荐出战：绯樱 / 输出型，按钮为立即开演。 | 这不是菜单游戏，第一步就是上台战斗。 | 按钮高亮、角色短入场、出现“推荐首演成员”。 |
| 30-60 秒 | 第一舞台确认页：星光初演。只显示目标：清完 3 波敌人。点击开始战斗后倒计时进场。 | 明白本局目标是清场，不需要先研究关卡和养成。 | 3、2、1 舞台灯亮起，60 秒内进入战斗画面。 |
| 60-90 秒 | 第一波慢速敌人出现，角色自动射击。屏幕左下提示移动，弹幕自动打最近敌人。 | 学会移动躲弹，理解射击是自动的。 | 移动时角色顺滑跟手；命中有应援粒子；击败敌人显示“应援 +5”。 |
| 90-120 秒 | 第二波出现带颜色提示的敌人，右侧切色按钮高亮，提示切到指定应援色。 | 学会切色会改变战斗效果，不是换皮肤颜色。 | 切色后弹幕颜色、命中特效、敌人状态立即变化。 |
| 120-150 秒 | 出现小精英敌，提示“切换形态扩大压制”。形态按钮高亮，从输出型切到染色型或辅助型。 | 学会形态会改变战斗手感。 | 切形态后弹幕范围、节奏或辅助效果明显变化，应援值加速上涨。 |
| 150-180 秒 | 应援值满，触发 C 位高潮。舞台灯光爆发，角色短时间强化并清掉最后一波。随后进入结算。 | 理解应援积累可以变成舞台高潮，清楚胜利后下一步。 | C 位大字、欢呼、镜头/震屏、伤害提升、清场、胜利结算。 |

### 机制出现时间

| 机制 | 出现时间段 | 说明 |
|---|---|---|
| 移动 | 60-90 秒 | 第一波只教移动和躲弹。 |
| 自动射击 | 60-90 秒 | 玩家看到角色自动攻击最近敌人。 |
| 切色 | 90-120 秒 | 只教一个颜色效果，不讲全套组合。 |
| 切形态 | 120-150 秒 | 只展示形态差异，不讲养成和数值。 |
| 安可 / C 位 | 150-180 秒 | P0 保底触发 C 位；安可是后续增强，不强塞。 |

### 胜利结算最小信息结构

1. 标题：公演成功。
2. 本局表现：清场成功 / 触发 C 位 / 剩余 HP。
3. 一个评价：S、A、B 或“应援评价”。
4. 主按钮：下一场公演。
5. 次按钮：再演一次。

### 失败结算最小信息结构

1. 标题：公演中断。
2. 失败原因：HP 归零 / 未清完敌人。
3. 一句建议：试试移动躲弹、切色压制、积累 C 位。
4. 主按钮：再演一次。
5. 次按钮：返回标题。

### 首玩中必须隐藏的系统入口

| 隐藏入口 | 原因 |
|---|---|
| 抽卡 | 会把首玩目标从“理解战斗”带偏到“获取角色”。 |
| 商店 | 第一局不需要消费与兑换。 |
| 社交 / 好友 / 公会 | 与 3 分钟战斗理解无关。 |
| 长期养成 | 会制造数值焦虑。 |
| 完整角色管理 | 只保留推荐出战，不开放详情页。 |
| 复杂章节地图 | 只保留第一舞台确认页。 |
| 背包 / 道具 / 任务 | 结算不展示掉落堆叠。 |
| 体力 / 门槛 / 锁关 | 第一局不能被资源系统打断。 |

### 需要程序支持的点

| 点位 | 要求 |
|---|---|
| 首玩直达路径 | 标题点击后进入推荐出战，再进第一舞台。 |
| 首局专用难度 | 敌弹慢、伤害低、敌人少，允许玩家犯错。 |
| 教学触发器 | 到时间或到波次后高亮移动、切色、切形态按钮。 |
| 自动射击稳定 | 自动锁最近敌人，第一局不要让玩家承担瞄准压力。 |
| C 位保底 | 150 秒前后通过加速应援值，确保第一局看到高潮。 |
| 入口屏蔽 | 首玩状态下隐藏抽卡、商店、社交、养成等按钮。 |
| 结算分支 | 胜利和失败都能进入对应最小结算页。 |

### 需要美术支持的点

| 点位 | 要求 |
|---|---|
| 推荐角色入场 | 绯樱短动效或立绘闪光。 |
| 第一舞台背景 | 简单舞台灯光，清楚表达“公演开始”。 |
| 自动射击反馈 | 弹幕、命中、击败粒子要清楚。 |
| 切色反馈 | 弹幕颜色和敌人受击状态必须一眼可见。 |
| 切形态反馈 | 形态切换要有角色光效或弹幕表现变化。 |
| C 位高潮 | 大字、灯光、欢呼、清场特效，做成首局记忆点。 |
| 结算页 | 胜利/失败两套清晰标题和主按钮视觉。 |

---

## P1 可增强

1. 在 150-180 秒加入一次轻量安可演出，但不能替代 C 位保底。
2. 给切色增加一句短语音或舞台字幕，例如“应援色切换”。
3. 胜利结算展示一条“你刚刚触发了 C 位”的回顾。
4. 第一局结束后解锁“自由选择成员”，但不在首局前开放。
5. 给失败玩家自动降低第二次敌弹密度。

---

## 后移

抽卡、商店、社交、公会、背包、完整养成、复杂章节地图、体力门槛、每日任务、活动、装备、好感度、完整多角色配队全部后移。

Phase 1 首玩只验证一件事：玩家能不能在 3 分钟内理解并记住“偶像应援弹幕打出舞台高潮”。
