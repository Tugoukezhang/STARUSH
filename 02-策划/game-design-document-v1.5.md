# 1. 游戏概述

## 1.1 产品定位

| 维度 | 内容 |
|------|------|
| **产品名称** | 《乱涂！彩世界》偶像版（代号：ST☆RUSH） |
| **游戏类型** | 弹幕射击（核心）× 偶像养成（外围）× 音乐节奏（视觉） |
| **平台** | 移动端优先（微信小游戏/iOS/Android），Phase 1验证 |
| **运营模式** | 抽卡+限定皮肤+期间限定角色 |
| **核心体验** | "打弹幕=应援，应援=打Call"的双向认同循环 |

## 1.2 差异化定位（vs 原版《乱涂！彩世界》）

| 维度 | 原版 | 偶像版 |
|------|------|--------|
| **世界观** | 抽象彩色弹幕 | 偶像舞台 + 应援文化 |
| **玩家角色** | 无角色 | 经纪人/制作人（隐含） |
| **角色系统** | 无 | 5人偶像团体ST☆RUSH |
| **应援机制** | 无 | 核心玩法（26种氛围组合） |
| **成长系统** | 技能树 | 团体等级 + 形态切换 |
| **视觉风格** | 抽象水墨 | 荧光棒 + 舞台 + 偶像应援色 |
| **敌人设计** | 抽象弹幕 | 练习生→黑粉→竞争对手→Boss |
| **结算反馈** | 分数 | 应援Combo + 安可爆发 |

## 1.3 核心卖点

> **"用打Call的方式打弹幕，用应援的逻辑打Boss"**

**卖点1：应援即战斗**
- 击杀敌人产生应援氛围（粉/蓝/黄/紫/橙）
- 氛围组合触发CP应援/联合应援/星尘冲击
- 应援不再是附属品，而是战斗力的核心来源

**卖点2：安可生态链**
- 弱点击破 → 橙色灼烧×1.5 → 安可状态
- 安可状态 → 全五色星尘冲击 → 30%真伤收割
- B3安可 ↔ B4舞台C位 = 双核爆发，独立积累

**卖点3：偶像可换装**
- 5人 × 3形态 = 15种战斗定位
- 限定皮肤 = 限定外观 + 限定被动
- 配队方案270种，策略深度充足

## 1.4 目标用户画像

| 维度 | 描述 |
|------|------|
| **核心用户** | 偶像系手游玩家（原神/崩铁/偶像梦幻祭受众） |
| **次级用户** | 弹幕射击玩家（东方Project/彩京爱好者） |
| **潜力用户** | 泛二次元用户（被偶像主题吸引） |
| **年龄层** | 18-30岁 |
| **性别比** | 女性偏多（7:3），但射击玩法对男性有吸引力 |
| **付费意愿** | 中高（月均50-200元档） |

## 1.5 Phase 1范围定义

| 项目 | 内容 |
|------|------|
| **验证目标** | 核心战斗循环 + 应援系统 + 5人偶像框架 |
| **可验证指标** | DAU/留存/应援Combo触发率/安可爆发频率 |

# 3. 战斗系统

## 3.1 弹幕射击基础

### 3.1.1 操作方式

| 操作 | 移动端 | PC端 |
|------|--------|------|
| 移动 | 虚拟摇杆/滑屏 | WASD/鼠标 |
| 射击 | 自动射击 | 自动射击/鼠标点击 |
| 切换形态 | 右侧按钮 | Q/E键 |
| 终极技能 | 左侧按钮 | 空格键 |

### 3.1.2 射击机制

| 项目 | 数值 |
|------|------|
| 基础射速 | 3发/秒 |
| 弹幕类型 | 5色应援弹幕（粉/蓝/黄/紫/橙） |
| 弹幕穿透 | 无（命中消失） |
| 基础暴击率 | **5%**（所有5色弹幕通用） |
| 暴击触发 | 暴击判定成功后（不限于特定颜色） |
| 暴击额外产星粒 | 每次暴击额外产生 **3颗星粒**（所有暴击均触发，独立于应援氛围） |

> **暴击系统设计说明（v1.3）**：
> - 所有5色弹幕均可暴击，暴击是全局属性，不绑定颜色
> - 暴击产星粒 = 独立机制，每次暴击均触发3颗星粒，不依赖甜蜜氛围
> - 甜蜜氛围的"暴击额外产生3颗星粒" = 甜蜜期间的暴击，星粒收益翻倍（6颗 vs 普通3颗）
> - 此设计确保粉色不是必选色——粉色的价值在于暴击率加成和甜蜜期星粒翻倍，而非垄断暴击

> **修正说明（v1.1）**：原v1.0将暴击限定为"粉色弹幕击杀时"，导致4色弹幕永不暴击，粉色成为必选，270种配队策略深度崩塌。修正后所有弹幕均有基础暴击率，暴击系统设计恢复完整性。

### 3.1.3 生命系统

> **v1.4 新增**：定义HP上限与回复机制。采用原型组推荐的**方案C：安可回血**。

#### HP基础

| 项目 | 数值 | 说明 |
|------|------|------|
| **HP上限** | **5** | 一命到底，不设多命 |
| 受伤判定 | 被敌弹击中 | -1 HP |
| 死亡条件 | HP降至0 | 公演失败，无复活 |

#### 回复机制

| 方式 | 回复量 | 触发条件 | 设计意图 |
|------|--------|---------|---------|
| 🎤 **安可回血** | **+1 HP** | 弱点击破成功 | 「安可 = 偶像返场」概念落地——观众欢呼让偶像重获力量 |
| ⚡ **C位回血** | **+1 HP** | C位模式触发时 | 「站上C位 = 满血回归」，应援值100的自然回报 |
| ❌ 击杀回血 | 无 | — | 不在击杀上做回血（与"击杀=回血"的通用套路做差异） |

> **设计意图**：
> - 安可回血 = 核心回复源。弱点击破成功不只是伤害爆发，更是生存转折点。完美契合"安可=偶像返场"的心理节奏——观众呼喊安可，偶像重返舞台。
> - C位回血 = 副回复源。应援值100触发C位模式同时也是生存保险，给予均衡/慢速玩法的容错空间。
> - **不设击杀回血**：避免陷入"清屏→满血"的无脑循环。回复绑定在「操作门槛」上（弱点击破需橙色灼烧+命中弱点），而非「敌人数量」上。
> - **上限保护**：HP已达5时，安可/C位回血不再生效，防止溢出。

#### 玩家血量管理策略

| 策略 | 说明 | 风险 |
|------|------|------|
| 激进收割 | 利用安可回血在低HP时强杀弱点，逆转战局 | ⚠️ HP=1时失败即死亡 |
| 稳健维持 | 靠C位触发保持HP≥3，稳定通关 | 🟡 通关时间较长 |
| 极限输出 | 放弃回血，最大化DPS，靠闪避硬撑 | 🔴 高操作要求 |

> **Phase 2 评估项**：是否需要增加HP上限（如团队等级提升至6-8HP）？是否需要被动/应援物增加HP上限？

## 3.2 应援系统（B2）

### 3.2.1 单色应援（5种基础）

| 应援色 | 氛围名 | 触发时机 | 战斗效果 | 数值 | 代价 |
|--------|--------|----------|----------|------|------|
| 🎀 粉 | 甜蜜氛围 | 击杀敌弹时 | **暴击率+20%**（基础5% → 最高25%）| 持续 4 秒 | 无 |
| 🔵 蓝 | 清爽氛围 | 移动时 | 范围内敌弹减速 30% | 持续 2 秒 | **自身受伤+15%** |
| 💛 黄 | 闪耀氛围 | Combo ≥5 时 | 获得「闪耀标记」，下次对敌伤害 +15%（可叠加3层） | 持续 3 秒/层 | 无 |
| 💜 紫 | 神秘氛围 | 站立不动 1 秒 | 腐蚀 DOT 2%/秒，叠满 5 层后移速 -10%/层 | 持续 5 秒/层 | 无 |
| 🟠 橙 | 热烈氛围 | 击杀敌人时 | 灼烧 DOT 3%/秒，防御 -10%；**弱点击破时×1.5** | 持续 3 秒 | 无 |

### 3.2.2 叠加规则

- 单色氛围：叠加层数上限5层，超出刷新持续时间
- 不同氛围：可同时存在，独立计时
- 蓝色自伤：独立叠加，含蓝色的三色组合自伤+15%固定值
- 氛围消失：持续时间结束或被新氛围替换

### 3.2.3 CP应援·双色Combo（10种）

| 组合 | CP名 | 战斗效果 | 触发条件 |
|------|------|----------|----------|
| 粉 + 蓝 | 甜蜜清爽 | 甜蜜暴击产星粒 + 清爽减速场 → **星粒雨减速场** | 同时命中粉+蓝弹幕 |
| 粉 + 黄 | 甜蜜闪耀 | 甜蜜暴击 + 闪耀标记叠加 → **星爆连击**（Combo 清零不重置计数器） | 累积粉+黄各≥1层 |
| 粉 + 紫 | 甜蜜神秘 | 甜蜜暴击 + 腐蚀叠层加速 → **心碎腐蚀** | 累积粉+紫各≥1层 |
| 粉 + 橙 | 甜蜜热烈 | 甜蜜暴击 + 灼烧蔓延 → **热恋灼烧**（范围扩散） | 灼烧目标被粉弹幕命中 |
| 蓝 + 黄 | 清爽闪耀 | 清爽减速 + 闪耀增伤 → **冰晶闪耀**（减速场内的闪耀伤害 ×1.5） | 减速目标被闪耀命中 |
| 蓝 + 紫 | 清爽神秘 | 清爽减速 + 神秘腐蚀 → **霜紫迷阵**（减速场附带腐蚀） | 冰冻目标叠加腐蚀 |
| 蓝 + 橙 | 清爽热烈 | 清爽减速 + 热烈灼烧 → **冰火交融**（灼烧伤害溅射到减速目标） | 冰冻目标获得灼烧 |
| 黄 + 紫 | 闪耀神秘 | 闪耀标记 + 神秘腐蚀 → **星尘诅咒**（闪耀伤害附加腐蚀） | 闪耀标记触发时叠加腐蚀 |
| 黄 + 橙 | 闪耀热烈 | 闪耀标记 + 热烈灼烧 → **烈阳冲击**（闪耀伤害触发范围灼烧） | 灼烧目标受到闪耀命中 |
| 紫 + 橙 | 神秘热烈 | 神秘腐蚀 + 热烈灼烧 → **炼狱之焰**（腐蚀触发灼烧，灼烧触发腐蚀） | 腐蚀+灼烧同时存在 |

### 3.2.3b CP详细参数（v1.4 补充）

#### 甜蜜清爽（粉+蓝）— 星粒雨减速场

| 参数 | 数值 | 说明 |
|------|------|------|
| 减速场半径 | **120px**（约3敌人宽） | 以命中点为中心，圆形区域 |
| 减速场持续时间 | **3秒** | 从触发时开始，独立于氛围持续时间 |
| 区域减速效果 | **敌弹减速 30%** | 与蓝色清爽氛围减速值相同 |
| 蓝色减速是否叠加 | **否（取最高值）** | 甜蜜清爽的减速场 = 蓝色清爽的"空间化表达"，数值相同不叠加。蓝色清爽仍是自伤+减速，甜蜜清爽将减速移至区域（不占自身氛围层） |

#### 甜蜜闪耀（粉+黄）— 星爆连击

| 参数 | 数值 | 说明 |
|------|------|------|
| "Combo清零不重置计数器"含义 | 闪耀标记的叠层**独立于Combo** | 一旦叠到N层标记，即使Combo中断归零，标记层数保留至持续时间结束 |
| 叠层方式 | 每达成Combo≥5时+1层（上限3层） | Combo每5的倍数获得1层（5/10/15各+1） |
| 持续规则 | 每层独立3秒倒计时，新增层数刷新该层 | 维持3层需持续Combo≥5 |
| Combo清零后 | 标记保留，但无法新增 | 已叠层数不掉；需重新打到Combo≥5才能继续叠 |

> **示例**：Combo=15时叠满3层闪耀标记 → Combo中断归零 → 3层标记仍在（3秒内陆续过期）→ 重新打到Combo≥5后可继续叠层。**本质是将"Combo维持焦虑"从惩罚转为奖励——断了不亏，维持赚更多。**

#### 热恋灼烧（粉+橙）— 热恋灼烧范围扩散

| 参数 | 数值 | 说明 |
|------|------|------|

| 蔓延上限 | **3个目标** | 1个原始灼烧目标 → 最多扩散至额外3个 |
| 蔓延后灼烧持续时间 | **2秒**（原始3秒的2/3） | 扩散灼烧不刷新原始灼烧时长 |
| 扩散触发 | 灼烧目标被粉弹幕命中时 | 每次粉弹幕命中均检测一次扩散 |
| 扩散冷却 | **无冷却**，但每次粉弹幕命中最多扩散1个目标 | 防止一次粉弹幕命中全部目标 |

> **战术价值**：热恋灼烧是小怪群的清屏路径——先给1个小怪上橙灼烧，粉弹幕命中它，灼烧扩散到周围3个，然后再扩散。适合练习生/黑粉密集波次。

## 3.7 伤害计算模型

> **设计目标**：明确各加成所属乘区，避免数值膨胀，提供平衡设计框架。

### 3.7.1 伤害公式

```
Final Damage = Base Damage
  × (1 + Skill Bucket Sum)
  × (1 + Form Bucket Sum)
  × (1 + Team Bucket Sum)
  × Critical Multiplier
  × Situational Multiplier
  + True Damage
```

### 3.7.2 乘区定义

| 乘区 | 类型 | 包含内容 | 计算方式 |
|------|------|----------|----------|
| 基础区 | 基础值 | 角色基础ATK + 武器ATK | 直接加算 |
| 技能区 | 加法区 | 应援氛围加成（闪耀+15%、甜蜜+20%等） | 加总后×(1+Sum) |
| 形态区 | 加法区 | 形态被动（输出型+20%等） | 加总后×(1+Sum) |
| 团队区 | 加法区 | 团体加成（本命+10%、默契+5%） | 加总后×(1+Sum) |
| 暴击区 | 乘法区 | 暴击率×暴击伤害 | 独立计算后× |
| 情境区 | 乘法区 | C位模式×2、安可+20%、全五色+30% | 连乘后× |

### 3.7.2b 应援氛围乘区完整映射

> **v1.3 新增**：所有应援氛围的数值、所属乘区、叠加规则一览

| 氛围 | 数值 | 所属乘区 | 叠加规则 | 备注 |
|------|------|---------|---------|------|
| 🎀 甜蜜（暴击率） | +20% 暴击率 | 暴击区 | 与基础5%叠加，最高25% | 不在伤害乘区 |
| 🎀 甜蜜（星粒） | 暴击额外+3星粒 | — | 甜蜜激活时触发 | 独立于伤害计算 |
| 🔵 清爽（减速） | 敌弹减速30% | — | 减速效果独立计算 | 不影响自身伤害 |
| 🔵 清爽（自伤） | 受伤+15% | — | 独立减益 | 战斗中叠加 |
| 💛 闪耀标记 | 伤害+15%/层（上限3层） | 技能区 | 加法叠加 | 层数可刷新时间 |
| 💛 闪耀（叠加上限+2） | 额外+2层 | 技能区 | 仅炼狱星陨时 | P2机制 |

> **数值上限设计原则（v1.3）**：
> - 单次普通伤害上限：Base Damage × 10
> - 单次真伤上限：Base Damage × 3（安可收割伤害不受情境乘区影响）
> - 情境乘区（C位×安可）同时触发时：最大叠加 = 2.4×（即 C位2× × 安可1.2）
> - 星粒单次产出上限：20颗/暴击（普通3 + 甜蜜+3 + 星尘雨×2 + ...）

### 3.7.3 各乘区详细说明

**基础区（Base Damage）**
- 角色基础ATK = 等级 × 5（Lv.50 = 250 ATK）
- 武器ATK = 武器等级 × 10（Lv.10 = 100 ATK）
- 总计：Lv.50角色 + Lv.10武器 = 350 ATK

**技能区（加法区）**
- 闪耀标记：+15% 伤害（可叠加3层 = +45%）
- 甜蜜暴击：+20% 暴击率（不影响伤害乘区）
- 其他氛围：见3.2节
- 计算：(1 + Skill_Sum)

**形态区（加法区）**
- 输出型：+20% 伤害
- 染色型：染色范围+50%（不影响伤害）
- 辅助型：团队氛围效果+30%（不影响伤害）
- 计算：(1 + Form_Sum)

**团队区（加法区）**
- 本命加成：最高等级成员+10% 伤害
- 默契加成：5人等级差≤5时+5% 伤害
- 计算：(1 + Team_Sum)

**暴击区（乘法区）**
- 基础暴击率：5%
- 暴击伤害：150%（基础值）
- 计算：未暴击×1.0，暴击×(1 + Crit_Damage%)

**情境区（乘法区）**
- C位模式：伤害×2（独立触发，应援值100触发）
- 安可状态：伤害+20%（独立触发，弱点击破后8秒）
- 叠加规则：C位 × 安可 = 2.4（乘法叠加，非加法）
- 计算：Product(Situational_Bonuses) = C位 × 安可 = 2 × 1.2 = 2.4

### 3.7.4 伤害计算示例

**示例1：普通攻击（无暴击）**
```
Base Damage = 350（Lv.50角色 + Lv.10武器）
Skill Sum = 0%
Form Sum = 0%
Team Sum = 15%（本命+10% + 默契+5%）
Crit = 否
Situational = 1.0

Final Damage = 350 × 1.0 × 1.0 × 1.15 × 1.0 × 1.0
= 402.5
```

**示例2：暴击+甜蜜氛围+输出型**
```
Base Damage = 350
Skill Sum = 0%（甜蜜暴击率+20%在暴击区，不在技能区）
Form Sum = 20%（输出型）
Team Sum = 15%
Crit = 是（暴击率25% = 5%基础 + 20%甜蜜，暴击伤害150%）
Situational = 1.0

Final Damage = 350 × 1.0 × 1.2 × 1.15 × 1.5 × 1.0
= 724.5
```

**示例3：完全体（C位+安可+全五色）**
```
Base Damage = 350
Skill Sum = 15%（闪耀标记1层；甜蜜20%在暴击区，不在技能区）
Form Sum = 20%（输出型）
Team Sum = 15%
Crit = 是（暴击率25% = 5%基础 + 20%甜蜜，暴击伤害150%）
Situational = C位×2 × 安可+20% = 2.4
True Damage = 30%（全五色真伤）

Final Damage = 350 × 1.15 × 1.2 × 1.15 × 1.5 × 2.4 + 105（30%真伤）
= 2104.6（未超上限3500 ✅）
```

## 4.2 三形态框架（G8）

### 4.2.1 形态定义

每个角色拥有3套舞台服装，对应3种战斗定位：

| 形态 | 定位 | 核心被动1 | 核心被动2 | 核心被动3 | 适用场景 |
|------|------|----------|----------|----------|----------|
| 🎤 **输出型** | 伤害最大化 | 伤害+20% | 暴击伤害+15% | 击杀回复+1应援值 | 速刷Boss/高压波次 |
| 💃 **染色型** | 控场特化 | AOE溅射范围+50% | 命中减速+20% | AOE持续+1秒 | 群怪清屏/CP应援触发 |
| 🎵 **辅助型** | 团队增益 | 团队氛围效果+30% | 团队暴击率+10% | 安可状态+1秒 | 协作通关/竞速 |

> **P2澄清说明（v1.1）**：原型组评审要求三形态有明确数值差异。当前版本补充了每形态的3个核心被动，确保输出/染色/辅助三条路线各有强度锚点。

### 4.2.1b 染色型弹幕射击映射（v1.4 补充）

> **v1.4**：原型组指出"染色"是偶像主题的叙事概念，弹幕射击引擎中没有原生染色机制。需将3个染色被动映射为弹幕射击可实现的战斗效果。

#### 映射方案：染色 → 命中溅射 + 减速

| 叙事概念 | 原被动描述 | 弹幕射击映射 | 实现方式 |
|---------|-----------|-------------|---------|
| 染色范围+50% | 弹幕染色范围扩大 | **AOE溅射范围+50%** | 弹幕命中敌人时，以命中点为中心产生溅射伤害，溅射半径+50% |
| 染色减速效果+20% | 染色命中的敌人减速 | **命中减速+20%** | 弹幕直接命中的敌人，移速-20%，持续N秒 |
| 染色持续+1秒 | 染色状态持续延长 | **AOE溅射持续+1秒** | 溅射区域的持续时间+1秒（含减速场/灼烧扩散/DOT） |

> **设计意图**：
> - "染色"在偶像主题中 = "用应援色感染舞台"，战斗中 = "弹幕命中后留下的持续影响区域"
> - 染色型不是"上debuff"，而是"每发弹幕都是一次小规模舞台效果"——命中点产生短时AOE，AOE内的敌人被减速
> - 染色型弹幕视觉效果：命中时爆开对应应援色的粒子圈（粉色=心形、蓝色=水滴、橙色=火焰等），粒子圈内的敌人受溅射效果
> - **与输出型的差异**：输出型是"单发弹幕伤害高"，染色型是"单发弹幕影响范围大"——群怪清屏效率 × 控场效果

### 4.4.5 属性汇总公式

> **属性体系**：5人各有ATK/DEF/SPD/CRIT+四个成长属性，HP统一为5。

#### 基础属性公式

| 属性 | 公式 | 说明 |
|------|------|------|
| **ATK** | `Base_ATK + Level × ATK_Growth` | 角色基础攻击力，随等级线性增长 |
| **DEF** | `Base_DEF + Level × DEF_Growth` | 角色防御力，减少所受伤害百分比 |
| **SPD** | 固定值 | 移动速度+射速修正，不随等级增长 |
| **CRIT+** | 固定值 | 额外暴击率，与基础5%叠加；固定不成长 |
| **HP** | 固定值 **5** | 所有角色统一，见 3.1.3 生命系统 |

#### 初始值 & 成长率

| 角色 | 色系 | 定位 | ATK@Lv1 | ATK/级 | ATK@Lv50 | DEF@Lv1 | DEF/级 | DEF@Lv50 | SPD | CRIT+ |
|------|------|------|---------|--------|----------|---------|--------|----------|-----|-------|
| 🎤 绯樱 | 粉色 | 暴击主C | 60 | +5.0 | **305** | 10 | +1.0 | **60** | 30 | **+10%** |
| 💫 苍海 | 蓝色 | 控场 | 48 | +4.2 | **254** | 20 | +2.0 | **118** | 35 | — |
| ⭐ 金星 | 黄色 | 增伤辅助 | 42 | +3.8 | **228** | 24 | +2.5 | **146** | 25 | — |
| 🌙 幻夜 | 紫色 | DOT特化 | 54 | +4.5 | **275** | 12 | +1.5 | **86** | 22 | — |
| 🔥 炎上 | 橙色 | 爆发收割 | 65 | +5.2 | **320** | 8 | +0.8 | **47** | 28 | **+5%** |

> **属性设计意图**：
> - 绯樱：高ATK+高CRIT，玻璃大炮（DEF偏低），依赖暴击和甜蜜氛围持续输出
> - 苍海：均衡型，DEF最高（含蓝色自伤+15%的承受力设计），SPD最快（适合移动触发的蓝色氛围）
> - 金星：ATK最低但DEF最高，不依赖自身输出，靠团队增益和闪耀标记增伤
> - 幻夜：ATK中高+DEF中低，DOT伤害独立于ATK成长，依赖腐蚀/灼烧层数
> - 炎上：ATK最高+DEF最低，极致爆发，"不是你死就是我亡"，弱点击破的收割定位

#### DEF减伤公式

```
实际受到伤害 = 敌方攻击力 × (1 - DEF / (DEF + 200))

示例：
├── DEF=0 → 伤害×1.0（无减免）
├── DEF=60（绯樱Lv50）→ 伤害×0.77（减免23%）
├── DEF=146（金星Lv50）→ 伤害×0.58（减免42%）
└── DEF=200 → 伤害×0.5（减伤上限50%）
```

| 场景 | 视觉处理 |
|------|---------|
