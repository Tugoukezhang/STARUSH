### 🔴 战斗域（6模块）

#### B1 — 染色弹幕射击核心
| 维度 | 说明 |
|------|------|
| **原型类型** | 交互原型 |
| **核心交互** | 触屏摇杆/点按移动 + 自动射击 + 弹幕躲避 |
| **关键机制** | 弹幕拖尾着色、弹道碰撞检测、多层染色叠加 |
| **原型覆盖度** | ✅ 已做（prototype-battle.html 中 F6），但仅模拟弹幕轨迹，缺少真实物理/移动操控 |
| **原型优先级** | ⭐⭐⭐⭐⭐ P0 |
| **技术要点** | Canvas弹幕粒子系统、碰撞检测（圆形/矩形AABB）、着色区域渐变覆盖 |
| **细分交互点** | ① 角色移动（8方向/摇杆）② 自动瞄准/手动瞄准切换 ③ 弹幕发射节奏 ④ 敌方弹幕躲避 ⑤ 地面染色扩散 |
| **音效/反馈** | 弹幕发射节奏音、命中反馈、受击震动、染色扩散音效 |

| 维度 | 说明 |
|------|------|

| **关键机制** | 5色标记条 + 5种元素异常 + 10种双色Combo反应 + 三色反应（⚠️见下方说明） |

| **原型优先级** | ⭐⭐⭐⭐⭐ P0 |
| **技术要点** | 状态机（0→满层→触发→衰减）、色盲双编码（纹理+色）、Combo命名弹出 |
| **细分交互点** | ① 红：暴击引爆+击飞 ② 黄：受击额外伤害×15 ③ 紫：递增腐蚀+减速 ④ 蓝：冰冻+暴伤提升 ⑤ 绿：持续伤+弱点击破抗性降 ⑥ 双色反应动画（熔岩橙/暗红玫瑰等10种）⑦ 三色反应 ⑧ 标记衰减动画 |
