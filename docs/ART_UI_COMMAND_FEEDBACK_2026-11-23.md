# 三角色技能指令与动作反馈

制作范围：恢复分支的正式 `game/`，本轮优先推进 UI、美术表现、技能动效。当前使用基底已有的角色与武器素材，后期三角色原生模型的缺口仍单独保留。

## 玩家能看到的变化与验收条件

- 右下技能区域保留固定触控位置，充能、就绪、施放、收势与暂停能明确区分；文字在明暗场景上都可读。
- 扫射按钮有分拍后坐反馈，突进有斜向掠光，重锤有冲击和余震。武器原图保留，亮部和辅助线分层表现。
- 反馈读取真实施放状态和动作时间，不从鼠标点击伪造施放，也不改变伤害、充能、攻击判定或移动规则。
- 安可显示实际剩余窗口，与动作一起暂停和恢复；充能环始终显示真实充能，动作条另行表示动作阶段。
- 连点、不可用点击、暂停、结束、死亡、换角色及重开不会残留旧动画。减少动态时保留状态信息，关闭位移和闪光。
- 构建、相关逻辑检查、正常入口的三角色实操、小屏及减少动态检查通过后提交并推送，核对远端。
