# STARUSH 手机试玩逐模块对照

本次以恢复分支的 `ca24f03` 为改前版本。按玩家从主页到出战、回看、后台的路径检查了 21 个页面，再按产品登记表核对 25 个模块。22 个已有运行逻辑，另外 3 个在设置页说明服务状态。新号、只记通关的旧式记录、带成绩的五章通关存档分别检查，存档样本由游戏自己的结算接口生成。

## 参考画面和具体用途

- 《乱涂！彩世界》主要看首页的人物与功能入口、章节地标、成员和装备选择。画面把当前对象放大，其他选择各自有固定位置。对照用了本作相同职能的页面；涂色单独看战斗地面和未涂区的分界。[一测界面实图](https://www.taptap.cn/moment/685538921035073313) · [涂色战场](https://www.taptap.cn/moment/685113367278388669)
- 《崩坏：星穹铁道》的技能近景用于核对人脸裁切和视觉焦点。本作安可的面积由竖屏里仍要移动、瞄准和看落点的需要决定。忘却之庭的说明只用于对照挑战前置条件。[技能近景](https://gmedia.playstation.com/is/image/SIEPDC/honkai-star-rail-version4.2-screenshot-20-en-13apr26?wid=1280) · [挑战规则资料](https://www.prydwen.gg/star-rail/guides/forgotten-hall)
- 《绝区零》的战斗截图用于核对人物前倾、武器伸向和攻击路径。录像店实图另用于核对场所、选项和经营状态的层次；静态攻击图只能判断构图，动作节拍用本作的实录复核。[战斗实图](https://gmedia.playstation.com/is/image/SIEPDC/zenless-zone-zero-v3-0-screenshot02-en-25jun26?wid=1280) · [录像店界面](https://game8.jp/zenless/610376)
- 内部使用确认过的红、绿、蓝立绘与 Q 版，以及负责人教程 v08 的九格采样。火星、刀光和前冲示例用来区分主要命中和次要碎屑。当前能复核的是采样画面，完整原视频和音轨仍未取得。[教程读取记录](TUTORIAL_REFERENCE_STATUS.md)

## 覆盖和验收范围

新号在 Chromium 的 320×568、390×844、430×932 三档各检查 21 页、135 个可用控件中心。390×844 再跑两种五章通关档。只有通关次数的旧式记录出现 159 个可用控件；补有对应规则、用时和受击纪录的测试档出现 161 个。多出的两个正是稳演、速演目标。用后者实点速演，页面带出 40 秒目标，确认后进入备战。检查包括图片加载、横向溢出、底栏数量、页名、命中遮挡和返回焦点；每一页都留下运行截图。由测试直接定位各页，另从真实入口点通成员、巡演、后台、场馆和设置流程。

五章图以各章出生点和同一人物拍摄。三、五章保留同一港湾的建筑轮廓，返场的轨道和编号只在第五章出现。新号与通关号的比较属于界面检查；没有用生成的通关存档代替手打通关或实体机帧率测试。

跨模块回归 220 项通过。另有导航、巡演与企划专项 32 项通过，本场目标与实战门槛专项 13 项通过。这些组有重叠，不相加。三人常规动作和两组减少动态效果在 Canvas 2D、软件 WebGL 各复测一轮，两轮均捕捉到实际出招帧。并发运行其他浏览器时有一次漏采风歌的短动作；单独复测捕捉到，当前数据不能代替低端真机帧率。

八个企划 WebP 已逐个解码。五张字图的左上像素透明，三张场景与道具图的左上像素不透明。旧生成清单没有在恢复目录和所查 GitHub 历史中找到；现有清单从实际文件重建，列出尺寸、像素样本、内容校验值，并保留未终审标记。[重建的美术清单](../reference/program-ui-manifest.json)

最终生产构建校验了五章和 834 项运行资源。构建仍有大包体提示。验收环境为 Chromium 的手机视口；实体机性能、完整教程原片和美术终审仍单列。
