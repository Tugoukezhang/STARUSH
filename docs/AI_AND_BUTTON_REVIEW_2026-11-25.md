## 把《乱涂！彩世界》的按钮放回实际操作中对照

公开实图中，当前能执行的主要操作有整块亮色，装备或章节的并列选项单独提示选中；弹窗的返回与确认有不同的图形和位置。复看了首页、装备和奖励窗口，也回看教程 v08 关于主次效果的采样。教程完整视频和音轨目前未取得。[参考实图](https://www.taptap.cn/moment/685538921035073313) · [教程读取进度](TUTORIAL_REFERENCE_STATUS.md)

| 本作的操作 | 发现与改动 | 验证 |
| --- | --- | --- |
| 选章节、看故事、前往准备 | 原先没开放的章节也亮得像能挑战。现在已通关、可挑战、未开放各有状态文字和不同票面。锁定的故事依然能读清解锁条件 | 同一份仅首章通关的档同时呈现三态。四档走完选章、切页、展开奖励和出战准备；锁定说明文字对比度 8.34:1。[实画对照](visual-qa/2026-11-25-next/tour-buttons.webp) |
| 暂停、继续、重开 | 原暂停图标在游戏画布上，键盘玩家需要知道快捷键。“继续”和“重新开始”还用了同一个播放三角。现在暂停是可点可聚焦的原生按钮，继续用播放图标和亮色主按钮，重开用循环箭头 | 点暂停后焦点进入“继续公演”，设置可打开和关闭；键盘焦点可回到战场。保留原快捷键及其他模式的暂停入口。[暂停菜单前后](visual-qa/2026-11-25-next/pause-buttons.webp) |
| 通关后挑排练目标 | 三个已解锁目标在小屏上只有 36 像素高，原来只测新号时没有走到它们。现在至少 44 像素，并给选中项加了勾号 | 使用五章通关存档实际打开、切换并检查状态和热区。[排练按钮前后](visual-qa/2026-11-25-next/rehearsal-options.webp) |
| 在资料页里用键盘换人 | 原来选完角色后焦点落到页面主体，按 Tab 从左上角重走。现在回到刚刚使用的“切换成员”按钮，从这里继续 | 名册、训练、成长、档案、休息室五个入口分别选择演员，检查收窗后焦点。 |

## 浏览器与设备

在 390×844 下，Firefox 153 与 Linux WebKit 26.5 都走过 21 页和 40 个二级窗口。两种引擎各有 262 次新号热区检查，名称逐项相符，并单独走通章节故事、奖励和出战准备。WebKit 在成长页首次等待按钮稳定超时，重开后从该页继续，后半程全部通过。Firefox 又用五章通关档检查 311 个控件。桌面浏览器的触摸模拟覆盖了布局和输入，实际 iPhone Safari、触屏手感与低端机帧率还需真机验证。

正式构建包含五章、834 项运行资源，保留大包体提示。用生产网页从主页选蔚蓝魔法师、开演、释放特技、暂停、打开设置再回到战斗，未遇到脚本异常或资源请求失败。
### 复跑指定浏览器与尺寸

在 `game/` 里启动 Vite，然后在装有 Playwright 及对应浏览器的终端运行以下命令。结果按引擎与视口保存为 JSON，可用 `STARUSH_QA_OUTPUT` 选择保存目录。

```sh
STARUSH_QA_URL=http://127.0.0.1:5173 STARUSH_QA_ENGINE=firefox STARUSH_QA_VIEWPORT=390x844 node scripts/qa-menu-details.cjs
STARUSH_QA_URL=http://127.0.0.1:5173 STARUSH_QA_ENGINE=webkit STARUSH_QA_VIEWPORT=390x844 node scripts/qa-menu-details.cjs
```

`STARUSH_QA_PROFILE=cleared` 检查五章已通关存档。`STARUSH_QA_VIEWPORT` 也支持 `smallest`、`compact`、`notch`、`tablet`、`desktop`。指定浏览器文件时使用 `STARUSH_QA_EXECUTABLE`，项目之外提供 Playwright 时使用 `STARUSH_PLAYWRIGHT_MODULE`。默认仍跑五种 Chromium 视口。Firefox 用真实浏览器的视口和触摸支持，WebKit 用 Linux 移动视口模拟，两者都不是实体手机。
