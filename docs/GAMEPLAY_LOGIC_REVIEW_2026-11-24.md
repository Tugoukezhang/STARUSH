# STARUSH 五章巡演与战斗反馈复查

本轮从主页的“继续演出”与“新公演”两个入口开始，检查选章、现场指引、暂停、失败、重试和通关记录。当前可玩的五章依次为星光初演、霓虹街口、终场合奏、雨后返场、回港加演。

## 参考如何用到游戏里

任天堂对《斯普拉遁 3》不同规则的介绍区分了涂地范围和模式目标。STARUSH 的背景颜料、必做设施、选线串场也有不同含义。我们保留地面涂色反馈，结算单列主设施与串场，告诉玩家再演时先做什么。[任天堂的规则介绍](https://www.nintendo.com/jp/ichikara/av5ja/03_en.html)

暴雪对《守望先锋》标记系统的说明强调标什么取决于现场目标和上下文。对应到屋顶，设备受压制时，箭头现在检查敌人是否确实关联到这台设备，以及它是否仍然存活；结尾清场时才引导玩家处理其他相关敌人。[暴雪的标记系统说明](https://overwatch.blizzard.com/en-us/news/23785337/an-inside-look-at-the-ping-system/)

内部使用 v08 刀光火星、v16 动作时间轴拼图及既有实机对照。负责人指定目录的教程原片仍未取得。手机布局、三套角色动作、颜料特效、五章建筑的上一轮改动和画面证据另有记录。[教程读取记录](TUTORIAL_REFERENCE_STATUS.md) · [四款竞品画面对照](COMPETITOR_VISUAL_REVIEW_2026-11-24.md)

## 玩家实际会遇到的情况

| 场景 | 这次改动及验收 |
| --- | --- |
| 继续旧局或开始新局 | 继续使用记录内的成员和章节。新公演到准备页确认替换记录。确认框打开时，底栏也停止接受输入。自动测试覆盖取消、替换与继续。 |
| 新档遇到锁定章节编号 | 在载入素材前先查真实解锁进度。浏览器用新档直接请求返港，进入星光初演，载入初演底图。 |
| 在巡演地图找下一站 | 四个锁定站直接写出要先过哪一章。320×568 窗口逐站滚动，四条解锁说明都有约 120×19 像素的独立浅底。地标保留灰度，说明清晰可读。 |
| 屋顶校音被打断 | 有可涂设施时，无关敌人不会把箭头引走。清场文字与箭头共用存活检查。未供电需连续校音 1.5 秒；供电后离开或遇遮挡可保留时间，被压制会清零。 |
| 暂停或失败后找断点 | 在清理场景前保留本区设施、串场和待校音设备。暂停与结算使用同一份判断。结算先给下一步，再给数字；在压轴开始前隐藏无关的声浪统计。 |
| 旧档、第五章与重复发奖 | 三章旧档保留原有通关记录。第四章解锁返港，第五章通关才完成整轮巡演。写入失败后重试同一次结算只算一次。 |
| 涂色跨地面分块 | 同一位置分别检验现用平涂和旧版立体墨边。两种模式的局部更新均与整面重画逐像素一致，覆盖分块接缝。 |

## 哪些已经验证

- 最后一组 20 个战斗、存档、结算、颜料测试文件共 227 项通过。另跑巡演地图 3 项通过，合计 230 项。五章各走东西两种分支，共 10 条，把所选支线和必需设施实际涂完，驱动校音时钟，检查两个区域的推进与完成。此组自动测试直接移动模拟角色到目标附近，另有独立用例检查压轴三个弱点。
- Chromium 模拟手机从主页选择蓝白学员，进入准备和实战，移动、施法、暂停、恢复，受实际敌人攻击从 5 血降到 0，出现失败页，再通过“重试本站”进入新局。失败截图能同时看清差几处设施、已完成数量与两个操作按钮。
- 生产构建和素材边界检查通过。本次没有做五章全程真人游玩，也没有采集低端真机的帧率和内存。
