## 制作时必须落到实物上的检查

1. 分层文件能单独显隐；还原后对照三张用户原图，保留五官、衣服、道具身份。
2. 头脸、眼口、头发和衣物分别控制。原生模型重新打开、运行模型实际加载，两者都要检查。
3. 头发/披带检查根部固定、分段弯曲、停止后的跟随和回弹；关键极值、组合角度不穿插。
4. 呼吸和口型检查首尾衔接、暂停、恢复、切换与回中，不能用整张图缩放冒充局部建模。
5. 特效检查预告、起手、命中、消退与真实判定的时间关系；手机尺寸下不遮住弹道和交互目标。
6. 完成模块时一并推送可编辑源文件、必要贴图、模型和运行资源，并确认 GitHub 上的实物可取回。
