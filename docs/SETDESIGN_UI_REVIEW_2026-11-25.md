## 设备、阅读与操作

- Chromium 五档覆盖 320×568、360×640、393×852、768×1024 和 1366×768。新号每档 262 项、五章通关档每档 311 项，共 2,865 次实际控件命中和尺寸检查。390×844 的 Firefox 与 Linux WebKit 各额外检查新号 262 项。[设备明细](visual-qa/2026-11-25-setdesign/audit/devices.csv)
- 额外打开七件装备的来源、首章战前说明和开场对白。用浏览器取得实际可见文本行的矩形，剔除收起的说明和重复文本，再根据实图确认。修后 390 宽档案标题位于 y=18–43，正文两行位于 y=686–736；320 宽从新号进入首章也能依次读完四句，再继续公演。[窗口实拍](visual-qa/2026-11-25-setdesign/windows.webp)
- 设备结果来自云端浏览器。实体机触感、移动 Safari 真机绘制和低端机长时间帧率尚未测量。局内结算专项中使用了游戏自身的胜负事件进入相应状态，实际打开、确认、返回和恢复则从可见按钮操作。[战斗检查范围](visual-qa/2026-11-25-setdesign/battle.md)

## 放大后再改过的地方

- 首页的开演票在 390 宽时，地标原本盖住“开”字约 24.23 像素，点击检测却能通过。改成插画和两行字各有自己的栏，章名与按钮文字都能换行。320 与 390 宽、两档像素密度、三名角色和长文本共 16 组均有 7 CSS 像素间隔。设备检查已增加图片右缘到两行首字至少 4 像素的回归项。[同按钮逐像素对照](visual-qa/2026-11-25-setdesign/home-action.webp)
- 用同一识别码匹配可见按钮，再把按钮自身裁出来。训练、挑战规则、休息室换人、场馆筹备等外面已铺新图，按钮本体仍沿用旧面。现已补绘本体和可用、按下、键盘与锁定状态。实选配件、升阶、排班和筹备之后也重新量过。[内页控件放大](visual-qa/2026-11-25-setdesign/inner-controls.webp)
- 备份窗原先最亮的竟是“返回设置”。现在只有读到有效备份后才突出“确认替换”，取消恢复可以回到刚才的操作，存档内容保持一致。故事的自动、日志、退出与场馆保存也单独重画。[系统与故事操作](visual-qa/2026-11-25-setdesign/window-actions.webp)
- 给图外的文字单独测量：被折叠或滚走的字不参与，筛出候选后回看截图。最终一轮对 651 段可量字迹的检查没有留下低对比候选。对真实行框另查过 61 个主页面和窗口状态、七个展开来源及五个战前/剧情状态，共 73 个状态、714 行可见文字，未发现文字相压。这种检查只覆盖采样情况，新文案仍需实画验收。[独立验收与测量方法](visual-qa/2026-11-25-setdesign/audit/README.md)

最终从 61 个状态匹配 289 项可见操作（同一动作出现在不同窗口会分别计数）。其中 286 项的本体样式或实际绘制它的伪元素有变化。剩余三项为首页、休息室的透明人物互动区，以及备份按钮下承接系统文件选择器的透明原生输入。人物直接响应触摸；文件选择使用重绘的中文标签和整块焦点。最后补核了七件背包卡的名称与状态、训练的三枚相邻工具和窗口中的路线/编排选项。[控件逐项数据](visual-qa/2026-11-25-setdesign/audit/controls.csv) · [装备标签](visual-qa/2026-11-25-setdesign/gear-labels.webp) · [角色、配件、说明三个训练入口](visual-qa/2026-11-25-setdesign/inner/training-tools.webp) · [章节与研究页签](visual-qa/2026-11-25-setdesign/window-tabs.webp) · [路线、配件、静音与排班](visual-qa/2026-11-25-setdesign/window-choices.webp) · [控件按下或选后实画](visual-qa/2026-11-25-setdesign/audit/control-families.webp)

## 冷缓存与资源回退

正式网页的首页冷缓存由 28 请求、13.45 MB，降到 25 请求、3.83 MB。首页只请求街口背景。背包或后台的图到真实入口打开时才读取。七步实走总传输由 23.57 MB 降到 9.01 MB。以 1.6 Mbps、150 ms 延迟各测一次，首页资源收齐由 69.44 秒降到 21.97 秒；首页布局首次出现分别为 6.99 和 7.56 秒。首次触摸耗时没有单独计时；另做了素材延迟期间的真实点击。标志压缩后与原标志作了透明度和深浅底逐像素比较。故意让小图不可用也能回退到原图。[每步请求与模拟慢网记录](visual-qa/2026-11-25-setdesign/loading.md)

## 发布核验

正式输出包含 869 项资源。通过正式网页读回本轮使用的 18 张场景、框、头像和标志，共 821,094 字节，与源文件及发布清单的 SHA-256 一致。另在独立目录从原稿重新导出，十八项与正式文件逐字节一致。二十三份界面自动化测试合计 150/150，覆盖三个角色、资源加载失败、切页后迟到的绘图回调、返回焦点、选择后存档、开机、转屏和恢复。

复查中有两处即使截到一张好看的静帧也看不出来。离开首页后，旧标志的错误回调原先还能继续请求大图；人物立绘报错后，先前的解码回调还能把坏图重新显示。两处均已修正，并用先失败、后收到旧回调的顺序重现、复验。

最终正式构建用三位角色各走一次普通模式，并补两组减少动态模式。五次均从游戏首页实点开演、首章说明、特技、暂停、设置和继续，均进入回充，应用无脚本异常或 HTTP 失败。
