## 后续制作与验收

1. 以原图确认 Q 版的发型、面部特征、服装大块配色和标志性道具。红发保留长马尾、护目镜、白橙黑外套与战术装备；绿发保留长发、白青金裙装、月饰与飘带；粉发保留双辫、蓝白花帽、海军蓝束腰、书本与小鸟。
2. 先核对已有候选是否包含同设计的可用 Q 版；无实物才重建。角色 ID 与旧存档关系保留，正式立绘模型的历史完成记录不重算。
3. 统一比例与战斗视角后补齐待机、移动、普通攻击、技能、受击和倒地。所有动作共享同一身份；枪口/握持点、脚底位置、地面阴影与实际判定对应。
4. 检查主页、成员页、准备页、战斗头像、技能/武器图标、结算、重开及资源失败路径。若主页固定红发，保留该历史规则，不能误把主页展示角色当成当前出战角色。
5. 真实入口逐角色验证移动与攻击、暂停恢复、受击/失败和重开；缩小到手机尺寸检查轮廓、遮挡与身份可读性。新动作不能用一张整图平移/缩放冒充完整制作。
6. 每完成一套可验收角色模块，保存源素材、图集、必要许可、接入代码和核对记录，提交推送并取回核验。
