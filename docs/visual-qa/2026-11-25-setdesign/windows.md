# 二级窗口细节

八组实画使用 390×844 的新号，窗口从游戏入口打开。左侧是本轮开工前的 `6812bab`。右侧保留真实角色、文字和操作区。[八组整屏前后](windows.webp)

| 小模块 | 开工前实画 | 本轮做法和检查 |
| --- | --- | --- |
| 窗口外沿和标题 | 换人、背包和任务全用同一条实色标题，很难看出从哪个模块打开。 | 用九切纸框留住固定宽度的四角，标题露出对应后台、器材间或巡演场景；关闭键单设深色面和原有名称。 |
| 名册、训练、成长、档案、休息室换人 | 头像列表使用约 2.3–2.5 MB 一张的原图，首屏可能只画出半截头发。 | 给三个签名牌加载同一原稿的 180 像素头像。五个入口在一倍、三倍像素密度分别检查，三人实际图片地址和自然尺寸均正确。选中项用深色证件底，其他成员使用浅券。 |
| 成员资料、能力与档案台词 | 一整块浅面把姓名和说明混在一起；旧档案引语是浅底浅字。 | 身份牌独立用深墨框，正文留在内页纸上；引语另用暗字、浅纸和窄色签。 |
| 七件装备的身份、数值与来源 | 名称、加成和来源是连续长条，锁定说明不易扫读。 | 实物与作用用货品签，效果值用内页记录，目标条件独立留白。可执行动作使用票根，未解锁可展开看获得条件。 |
| 章节页与开演说明 | 章节目标、奖励与继续的按钮像同一种底板。 | 页签用深色选中，章节目标包进说明纸，奖励各有小格。规则整行可点，首次说明保留页签和战场目标。 |
| 剧情对话、场景与说话人 | 场景标题直接叠在亮天空，读白位置容易随舞台画面挤动。 | 地名用深墨底，说话人用小铭牌，台词用独立对话纸。320、390、768 三档下连续翻句，正文始终在后续按钮上方；320 宽首次开场实际读到最后一句并进入战斗。 |
| 手记、编排、场馆及企划 | 展开与收起、排班草稿、成员记录和目标提示难以区分。 | 手记可读章节保留一张档案纸，未解锁章节只留标题和原因。编排用页签，排班的在选节目、草稿、进度清单和目标说明各有对应底色。 |
| 设置遮罩 | 390×844 的首页可铺满屏，设置遮罩却只盖住 y=75 到 769，首尾漏出较亮的旧页面。 | 遮罩沿菜单宽高和安全区定位。320、390、768、1366 四档分别从上下边缘取点，均由窗口接住。 |
| 音量和状态显示 | 滑杆、百分比与当前设置挤在同一张白纸。 | 声音区域使用调音台面板，两种音量带实体感推子，数值有独立浅色显示窗。四档均实点静音、解除静音，再用键盘调到 5%，核对推子与显示同步。 |
| 存档导入、焦点与错误提示 | “选择备份文件”下面再出现一枚浏览器文件按钮，操作重复。 | 中文标签和原生文件输入占同一热区，聚焦时整个文件框描边。四档用真实选择器传入一份无效 JSON，均提示校验失败，未显示恢复按钮。 |
