## 按钮首轮与返修

390 宽的新号在各入口首屏匹配到 289 个可见按钮、折叠项与原生输入。相同动作从不同窗口进入会分开计数；五个尺寸的滚动命中另见上表。本轮直接比较控件本身和伪元素，286 项显示本体样式有变化。即使本体沿用，内部图标、文字、承托框或周围场景也可能发生变化。[逐个可见控件](controls.csv)

第一遍单挑出 14 项控件，其本体仍是旧面，当前像素变化不足 9%。包含训练、两种挑战的规则、休息室双操作、场馆准备、服务、剧情导航、窗角关闭与排班。反馈给制作后按同一位置取样，14 项能看到本体或实际图面的变化。图中保留中间状态便于比较。[14 处实裁对比](retouched-controls.webp)

最后单列了剩余 30 项中真正承担视觉操作的 27 项，涉及七件装备、训练工具、资料目录跳转、三条串场路线、成长装备选择、排班成员和两处静音。补画后，289 项中共有 286 项的本体或伪元素样式确实改变。另三项负责首页与休息室两处人物透明触区、备份文件的透明原生输入；立绘和导入标签各自承担可见面。

用通关档对八个家族独立抽检 13 次真实按下、松开和操作结果，分别核对了窗口与跳转目的地、重开后路线和装备选择、排班草稿中的当前人以及两处静音勾选。缩放与候选数量不同的控件均保留各自的实画。[八组本体和操作状态](control-families.webp)

章节详情里的剧情页签和编排研究中的四个选项也定点复核。五个控件的本体均有改变，同位置可见像素变化分别为 34.4% 与 36.8%–41.2%。

在 320、390、768 宽的浏览器里从首页到战场采了 15 次主操作。分别暂时去掉装饰图标与活字，量真实墨迹间隔。首页图与字的布局间距 7px，巡演 9px，出战准备 10px，暂停后的继续 9 至约 13.8px。墨迹之间最少仍有 9px。“确认编排”使用纯文字票面。另在设备脚本里固定了首页两行首字距实物图至少 4px 的回归检查。[实测间距](icon-spacing.csv)

## 框里文字是否能读

从可见文本节点读取实际换行后的每行边界，剔除被关闭/隐藏的部件和滚动容器裁掉的部分，忽略嵌套组件重复的文字。合计 73 个画面状态、714 行。范围包括 21 页、40 窗、七个手动展开的配件来源，以及 320 宽实际首章的战前说明和四段对白。检查的是这些存档及视口中实际绘出的行。最终检测到 0 个状态出现不同文本行明显相压。[逐状态几何结果](text-geometry.csv)

在制作中，章节现场档案→开场回看曾把对白挤到抬头上方。修复后，390 宽标题落在 y=18–43，正文两行在 y=686–736；320 宽的开场按“下一句”逐段检查，正文从 y=419 起。训练姓名、企划的“通关 0/5”、名册台词、剧情地点和休息室的“本机记录”也曾出现深字落在深底或浅字落在浅底的情况，均重新取图核实。

另外在同一画面短暂隐藏文字墨迹，比较原像素与其后的实际纸面。旧版抽到 649 段可判定的实字，新版 651 段。用普通正文 3.5:1、大字 2.9:1 作为查找明显发灰字的筛查阈值；旧版有 4 个候选，最终新版有 0 个。该抽检只用于发现实画问题，不等于每个字均符合无障碍标准。

Firefox 与 Linux WebKit 另各用 390×844 的新号走完 21 页、40 窗和 262 项控制。两者均通过，最短边约 44 CSS px。
