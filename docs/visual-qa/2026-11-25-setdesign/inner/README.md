# 16 个内页的背景、画框、文字和操作

每个链接都有新号 390×844 的游戏整屏和一个局部放大。左侧取自 `6812bab`，右侧为本轮。场地图片和字图解码后才截图。换成员、换场地、点击锁定条件时继续读真实存档。

这次对照《乱涂！彩世界》时看了角色页的留白、三列图鉴、奖励窗口、分段任务清单、两种模式入口，以及深底状态明细。参考里的角色页把操作放在人物轮廓以外，清单则把复杂场景留在表外，留给正文的纸面很平静。不同模块因而有不同的做法。指定教程 v08 采样图里，主体、亮部和干扰纹理可单独辨认，此处用来检查灯光、纸框和正文相叠时字是否还能读。[公开参考图来源](https://www.taptap.cn/moment/685538921035073313) · [教程读取记录](../../../TUTORIAL_REFERENCE_STATUS.md)

| 实画 | 大背景和场景衔接 | 读文字的小模块 | 操作和状态的小模块 |
| --- | --- | --- | --- |
| [演出档案](records.webp) | 原先柜顶只有一条横幅，后两章下方留一大块米色。现在整页位于唱片档案室，五张照片卡独立摆放。 | 成员成绩装进暗色读数框；章节照片的纸边、名称、空档说明分开。 | 三个档案工具原先共用箭头，现在打开成员、说明和现场档案时有不同图标，整张章节卡仍是点击区。 |
| [章节现场档案](chapterArchive.webp) | 横幅、正文、底部空白原先各成一块。现在档案室贯穿页面，玩家所选章节的实景照片有自己的相框。 | 故事单独放在大纸页，最近现场和目标事件各有折页；故事不可读时单独给出文字条件。 | 五个标签原来用了固定深色中文字图，深底时难读。现在用可变字号的原生章名，选中、未选中、锁定都能识别。 |
| [成员训练](workshop.webp) | 旧训练海报的大斜切覆盖了场景。改由排灯与设备工作区围住角色，立绘轮廓在中间。 | 人名、定位放在暗色铭牌；训练阶位与前后增益在下面独立的读数屏。实画复查后把姓名换成亮字。 | 换人和配件工具靠右，底部材料是否充足决定按钮状态，普通浏览不会消耗材料。 |
| [成长规划](growth.webp) | 旧器材横幅下方是空白纸面，现在观景台一直延伸到页脚。 | 人物情况、当前与规划数值、应用成本分别用铭牌、对照纸和暗色状态条。 | 当前规划格使用浅黄绿，并保持当前、规划两列的原有数值；成员、配件和成长资料显示各自的图标。 |
| [压轴排练入口](playhub.webp) | 两幅模式图过去漂在空白画布上。现在共用大排练厅作背景，两张海报保留各自的模式插画。 | 模式名贴在海报内，保存与解锁条件另占下面的纸签，长汉字可换行。 | 两张海报都保留完整点击面，右侧入口箭头与右上角的锁分开。 |
| [本场目标](goals.webp) | 旧页只有一条背景横幅，三个目标与底部说明像一张名单。现在排练场能从票券两侧和下方看到。 | 预选和已确认仍是两条独立信息，合放在最下方的说明卡。 | 选中目标使用整张浅黄绿票，未开放的票使用暖白底；锁定原因以深色字显示。 |
| [编排组合](library.webp) | 设备桌上的阶段区与下方预览处在同一工作台，列表外围不再留大片纯色。 | 选中效果有纸签，数值预览使用深色显示器，三种信息可以顺着读下来。 | 第一段、第二段当前格有浅亮底，四种合法选项各自显示真实效果图标；查看详情不改变游戏配置。 |
| [成员介绍](recruitment.webp) | 两种纯色斜切的旧人像底改为化妆间，背景贯穿成员选择和人物简历。 | 姓名与武器定位有独立铭牌；角色介绍由暖纸页承载。320 宽下检查长角色名后，缩小边距，避免一个字独占一行。 | 三枚头像票保留已选标记，查看成员阵容单列在人物简历下方。 |
| [巡演后台](backstage.webp) | 原先页首嵌图、下方米色底互不相接。改成一间办公室，从窗户一直连到桌面。 | 存档里的通关场次、练习笔记放在窄读数条上，两个主要入口的标题留在各自海报。 | 两个演出入口占大卡。下方四项功能归入同一张工具页，避免六个按钮全部争夺注意力。 |
| [成员休息室](lounge.webp) | 人物前景与整幅化妆间共用同一画布。 | 姓名签与对白框有独立底色。底部“本机记录”原来直接压在插画上，现有自己的深底。 | 回答和话题有独立小票，当前项的浅黄绿纸面与正文框分开；触摸人物仍能互动。 |
| [场馆事务](venue.webp) | 当前房间仍显示真正的场地，房间照与操作面板之间露出场馆环境。 | 房间姓名铭牌、排班与筹备区分别位于相片与独立纸卡。 | 三枚房间控制使用暗色标签；当前房间改为亮票。未排班、待筹备照常保留文字条件。 |
| [公演企划](events.webp) | 真实章节的场地照放在巡演地图前；下方路线带和辅助操作不再落在空白底上。 | 可出演状态和通关数字有独立状态条。实画检查发现进度继承了旧深字，已把通关数字改成亮字。 | 五站进度单独放在纸带上，章节进度和目标详情各有纸签，主操作仍进入当前巡演。 |
| [压轴连演](finaleTrial.webp) | 模式海报保留街区实景，外围与大地图相连，展示三站属于一次连续巡演。 | 规则摘要与解锁条件使用两种独立深框，说明可脱离复杂的海报纹理阅读。 | 三个必要场地各有附带状态的地标卡。通关档显示实际可选的两段编排。 |
| [压轴排练室](rehearsal.webp) | 原先顶部画出一幅排练场，中部又出现一幅不相接的底图。现在整屏共享一幅连续的排练场。 | 场地条件独立于本轮配置折页。打开后能读到当前人物与数值。 | 单站地标使用横向条目；已解锁档的场地、课题、编排各自成组，仍可切换和确认。 |
| [练习广场](sideplay.webp) | 原有嵌画与空白下半屏改为整幅排练厅，前后舞台连贯。 | 成员信息有亮纸签，两本练习册各有带名称与说明的纸脚。 | 两个入口错开摆放，实际功能仍分别进入编排资料与演出目标。 |
| [设置与服务](services.webp) | 过去上方器材横幅、下方大块米色。现在从设备台上方的架子一直看到桌面。 | 本机存档汇总有一块完整读数屏，设置和备份装在同一台服务面板。 | 声音与演出设置、本地完整备份同级；服务状态查询独立。操作结束后回到原来的入口。 |

局部对照取自上面的实际屏幕，位置会跟随标题、按键和文字框移动。16 页同时以 320×568、390×844 和 1366×768 检查。截图中的手机是浏览器模拟。
