# 战斗中的小框、文字和操作

对照上一轮版本 `6812bab`。图中截取了真实控件的位置，安可取 360×640 视口，其余取 390×844。关卡计时、角色血量和受击数随实际取样时刻变化。[战斗前后实图](battle.webp)

| 玩家要看的小块 | 旧版实画的问题 | 本轮处理 |
| --- | --- | --- |
| 头像、生命和热度 | 生命与热度放在相同的紫色横条上，和地图边缘混在一起。 | 生命改用深青仪表，头像有暖色窄框；热度独立用深紫灯牌。低血量继续显示危险色和实际数值。 |
| 战斗目标、倒计时和详情 | 目标、时间、小按钮视觉重量接近，展开后是一块平的深色矩形。 | 目标用窄提示条，计时独立反白显示；详情采用深青设备面，打开时按钮亮起，能够再次点回去。 |
| 暂停键 | 暂停图形曾与顶栏使用相同的墨色小块。 | 画成独立浅色设备按键，图标与点击面分开。320 宽实测热区 44.1×44.1 像素。 |
| 特技和安可技能键 | 图案托底是通用斜切块，角色武器和充能条都挤在同一个色面。 | 武器保留原画，下方显示真实充能。回充时使用深色仪表，就绪时亮出浅色卡面。 |
| 安可弹出 | 侧卡已有合适尺寸，角色名和清弹数却压在装饰斜线边缘。 | 肖像与文本各有安全区，深色标题条配角色专属返场色。三位成员的实际侧卡面积均为战场的 6.819%，中央命中及点击穿透均通过。 |
| 暂停标题与角色 | 装饰色块占据标题后半，和角色重叠。 | 办公室灯光作为环境，左侧暗化放章节和成员名，右侧只出现当前成员。继续、设置、重开和返回分别用票根和工具键。 |
| 暂停进度和配置信息 | 正文和动作同排裸露在底色上，难判断它能否点击。 | 设施、串场和行动目标写在独立的纸条内；配置仍可展开。继续、设置、重开及返回在 320 宽均高 48 像素。 |
| 编排桌、选项和确认 | 选择区是满屏单色底，选项与说明在同一平面。 | 用排练场当工作空间，候选为浅色指令卡；选择后打勾并点亮卡片，影响说明落在下方独立便签内。确认之前按钮禁用，确认热区高 48 像素。 |
| 章节结算的标题与成绩 | 斜线盖住部分场地，四个统计与标题同色。 | 标题引用当时角色和章节背景，统计独立成仪表，收获和再演提示放在档案便签。胜负各保留实际下一步。 |
| 章节结算的收获、故事和底部按钮 | 发放奖励、阅读剧情与离开使用相近的框。 | 奖品与故事各有内容纸面，详情保留折叠操作，前往下一站或重试共用底部主票。320 宽返回与再演的次按钮高 44 像素。 |
| 单站压轴排练结果 | 旧黑标题框和人物像是与成绩单分开的两张贴图。 | 排练场上方显示课题结果，下方依次可读完成条件、操作及血量。实测结束并点击返回排练准备。 |
| 三站压轴连演结果 | 站数与单站排练使用同一种黑标题，继续下一站和重来难以区分。 | 连演以巡演夜景为题头，每站结果装入记录纸，继续下一站用主票，重来与返回并列。实测完成第一站并回到连演准备。 |

对照了彩世界确认窗的暗底与独立亮面、崩铁实战画面里角色与动作提示的主次、绝区零战场里持续信息与短反馈的位置。制作前查看了指定教程 v08 的采样图，用主体和亮部分层的方法检查武器图、充能与危险提示的对比。[彩世界参考](https://www.taptap.cn/moment/685538921035073313) · [教程读取记录](../../TUTORIAL_REFERENCE_STATUS.md)

三个 Chromium 视口为 320×568、390×844、768×1024，每档检查九种状态，另有三名角色的安可与通关档两种挑战结算。测试从实际菜单开演，再用测试入口调用游戏自己的编排和胜负结算事件。按钮切换、暂停与恢复、拖动摇杆、角色技能、重试和返回均在真实游戏页面操作。战场与回充相关专项 19/19，挑战和排练专项 31/31。
