## 各处具体改动

| 小部件 | 上版实画与参考的差别 | 这版怎么改、怎么验 |
| --- | --- | --- |
| 内页标题 | 页名和页边都在整条奶油底上；参考图 3、5 的页名集中在独立深色题签里。 | 纸夹上装了一枚按字长伸缩的深紫名牌。手机上实际读到了完整「装备背包」，也保留了结尾的空白。 |
| 返回和设置 | 两个动作共用同一形状的黑底，小图标承担了全部区分。参考图 10 把返回独立在主动作一侧。 | 返回与题签同属紫色，设置装在深青设备面板上。内页以键盘 Enter 返回，首页用 Enter 开设置、Escape 关闭，触控框都是 44×44。 |
| 练习笔记数字 | 原来是一块近似按钮的深色直角块，音符很小。参考图 1、26 以物件和数字共同指明资源。 | 金色音符圆章跟随实际数字，保留状态语义及等宽数字。圆角计数牌和旁边可点击的方形设置键各有轮廓。 |
| 四个常驻入口 | 深底和固定 60 像素按钮之间有大片空隙。参考攻略的第 2 张近景用不同剪影判断入口。 | 四枚演出物件放在同一浅色台面。按钮铺满各自一列；320 宽实测 75–76 像素宽，390 宽实测约 93 像素宽，两档高均为 57。 |
| 当前位置与鼠标经过 | 当前位置和主操作共用大块亮黄；在大屏移到其他入口时，按钮底色维持透明。 | 当前入口用整张深紫名签，在名称前点亮一盏小灯；其余保持纸底。在 1366×768 下，鼠标移到可用入口后有单独的浅麦色和底边。 |
| 键盘焦点与按住 | 原黄线放到新的浅纸上不容易辨认。 | 用键盘移到巡演，实测焦点为深青色，内衬浅色线，在选中名签与纸底上均有边界。按下按钮有明暗反馈；320×568 开启「减少动态」时图标无位移。 |
| 主要操作 | 旧票面的黑黄斜纹占用右端一大块，临近章节名和行动文本。参考图 7、10 给动作名留出连续底色。 | 开始公演使用单独绘制的浅黄绿票根，两端切口提示可操作；内字和章名仍可读取。 |
| 次要动作 | 切换成员是一整块纯色矩形，与名册里的说明栏相似。 | 切换成员使用带边角的独立签条。名册真实打开后截取了这枚按钮。 |
| 锁定条件 | 章节锁定卡在旧地图上很像空的表格方格。 | 巡演把地点与原因放在同一张报名单。新号读到「霓虹街口／通关星光初演后开放」，仍使用原生禁用状态。 |
