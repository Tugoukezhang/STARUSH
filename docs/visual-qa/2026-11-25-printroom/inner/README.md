# 16 个内页的整屏对照

每张图都并排放了同一页面的改前和改后。两侧均由 390×844 的 Chromium 手机视口使用新号打开，等待场景、角色和字图加载完成后截图。测试从游戏的实际页面入口渲染，没有用排版稿替代运行画面。[16 页改后总览](index.webp)

对照《乱涂！彩世界》公开实图时，主要看人物与工具按钮怎样分开、成组选择怎样排、确认和条件说明怎样区分。本作使用演出场景、原有三名成员与真实章节进度。[竞品画面](https://www.taptap.cn/moment/685538921035073313)
