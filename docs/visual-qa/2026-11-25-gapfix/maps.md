# 五章地图复核

第一章在店门口补了唱片灯箱，装卸门有铰链、把手与提示开缝的黄纹。第二章的耳机灯和杯灯能从轮廓区分。两家店与街心设备之间的电线沿真实依赖画出接线与方向，支路各自通电。未解锁设备的锁扣钉在设备上。

港口帆灯有自己的机身。左侧是青色单镜头，右侧是琥珀色双镜头。上色后，十二段刻度贴在实际站位半径，四处长刻度标出边界；人物站到范围内时，灯圈按实际读数填亮。雨台的设备换成带音叉的校音台，中央地面降低细斑密度，两旁旧漆、整幅板缝和井盖保留。已接通后备供电的设备增加一对琥珀电芯。归港入口的棚屋增加卷幅和器材车，同一栋楼的暗色与上色状态都能认出。归港常驻电线与返回的脉冲用不同形状表示，暖色脉冲沿实际回程显示箭头。
