# 三位角色从名册到散场

上轮最明显的断点在蔚蓝身上。名册里她拿着书，一进居所却变回旧角色，回到战场后编排又叫她用重锤。这次用同一批正式设定核过名册、休息室、独立居所、编排和胜负结算。竞品对照沿用《乱涂！彩世界》公开图中同屏人物、道具和地面颜料之间的颜色提示。休息室的三种表情与胜败反馈按本作原画和玩家操作复核，竞品同一角色对应场景的实机证据仍有限。[上轮角色问题](../2026-11-25-gap/systems.md) · [上轮美术对照与来源](../2026-11-25-gap/art.md) · [上轮胜负对照](../2026-11-25-gap/settlement.md)

## 复核条件

- 浏览器模拟 390×844 的触屏视口。独立居所采用 Chromium 软件 WebGL；主游戏核对使用 Canvas。对话、出战确认、放技能、选编排与重试均实点。六个结算样本在正常进入可操作的首章后，调用游戏已有的胜负事件，让三位角色按相同条件出现在结算页。这个样本适合看角色表现，不用于判断首章难度。
- 直接打开无 `member` 参数的旧居所地址，等到三维场景真正就绪。旧陪伴记录选择蔚蓝时出现蔚蓝；陪伴记录损坏、出战为风歌时出现风歌；两份记录均不可读时出现默认的战术女武神。
- 有效的旧后台存档只保留上次话题。首次写入新回答时仅接回可证实的旧记录。自动检查覆盖无写入读取、单独保存选项、坏档保护、答完换人、最近话题、新旧版本备份与真实部署后的返回页。
- 教程采用项目内已留存的角色表情和立体着色抽样，完整原视频的获取状态见教程记录。本轮观察者是制作端，遮住结算标题后交三位新玩家盲认仍待实人验证。手机项是浏览器模拟，尚无原生 iOS Safari 与 Android 真机报告。[教程读取记录](../../TUTORIAL_REFERENCE_STATUS.md)
