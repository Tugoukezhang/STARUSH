# 老街的追兵会不会被墙卡住

本次从第一章实际主菜单、巡演、演出准备进场，用女武神把一只普通滚轮追兵从唱片店正门引到店后。双方起步时可直接接近。玩家按方向键向左进入巷口，再向北、向右拐到后街；追兵一直由战斗场景自己移动。图下方绿线是玩家，砖红线是同一只追兵，灰块取自这次场景里的真实建筑碰撞范围。[连续取景与双方路线](pursuit.webp)

| 附近的游戏时间 | 实际发生什么 |
| --- | --- |
| 起步 | 玩家在 (395, 1476)，追兵在 (416, 1508)，两者之间可以走直线。 |
| 约 7.05 秒 | 唱片店挡住直线。玩家已进入左巷，追兵还在商铺南侧，随后沿左侧外墙追上来。 |
| 约 12.65 秒 | 追兵从店铺左上角探出，和后街的玩家重新有了直达路线。 |
| 约 15.92 秒 | 在此后的首个近距离采样，追兵离人 21.33 个世界单位，已小于复核接近阈值 24。 |

逐次检查 224 次战斗更新，以敌人实际 12 单位半径检查每一小段位移，穿越实体建筑的次数为 0。遮挡和重新可见各发生一次，追兵 89 次使用了不同于玩家当前位置的导航点。89 是更新次数，途经同一个拐点也会统计。第五章仓库的独立复测从墙两侧相隔 200 单位开始，追兵最大横向偏离起始直线 119.77，最后距离 22.20。[此前仓库取景](../2026-11-25-next/warehouse.webp)

普通追兵一直以玩家当前位置为目的地。障碍挡住时，它用自己的身体半径确认下一步，绕到能直行的地方再继续。玩家拐走后，路线会重算；合法下一步为空时，追兵会停住。第二、三章还有看守设施的敌人。玩家离岗点超过 216 单位时，未出招的守卫可以回守；玩家靠近时重新接敌。已承诺的冲刺沿先前亮出的地线走完，之后有 720 毫秒收势。设施完成后会解除该守点。[普通追击与守卫场景入口](../../../game/src/scenes/BattleScene.js) · [拐点与身体净空](../../../game/src/utils/streetChaseNavigation.mjs) · [领地与冲刺规则](../../../game/src/utils/chapterChaserContent.mjs)

## 两只追兵先后被挡住时，下一枪选谁

在同一章另开一场，把两只游戏生成的滚轮追兵放在店后街。测试临时提高本场普通怪数量上限以取得第二只，再恢复原值。用正式的下一枪选敌函数连续读取四个状态。

| 条件 | 下一枪实际选中 |
| --- | --- |
| 两者都在同一条无遮挡的路上，甲距人 29，乙距人 47 | 甲 |
| 甲移到商铺背面，乙留在原处 | 乙；甲与玩家的直线已被挡住 |
| 乙也移到墙后 | 无可选目标 |
| 甲回到原来可瞄的位置 | 重新选中甲 |

另做一次目标失效复核。把玩家对象短暂标成失效后，同一普通追兵两轴速度都变成 0；恢复玩家对象，在下一次有效更新重新以每秒 48 单位追击。此处是单独注入的保护状态，正常绕墙时玩家始终有效。四档选敌读取的是实际下一枪的决定，箭头、触屏手动覆盖和取消后的画面由同轮战斗取景复核。[目标提示与触控反馈](combat.md) · [选敌与失效解除回归](../../../game/tests/ownerPublicTargetFocus.test.mjs)
