# 三位角色与六类敌人的动作复比

三位角色向上走能看到后脑和背部，向下走能看到脸、胸口和各自的道具。首章的发射器打开音箱两翼、聚光队长掀开灯罩、干扰器抬起两根天线。它们分别跟随出弹或设施受压制的游戏事件。[角色实战前后对照](performers.webp) · [敌方原画与本轮图格](enemy-poses.webp) · [设备真实战斗画布](enemy-live.webp)

## 逐项复查

| 玩家正在做什么 | 本轮实画与判断 |
| --- | --- |
| 短按、起步、急停、反向 | 三人各有四格背面步态、四格正面步态，左右沿用原形。步频跟实际位移，松手后原地保留踩下的那只脚 84 毫秒，身体在 155 毫秒内回稳。斜向输入在两轴接近时保持上一次朝向。|
| 女武神移动射击 | 枪的后坐与脚的迈步分开。横着跑时按前进或后撤顺序迈步；上下行时若瞄着侧方，使用侧举枪的肩和朝前、朝后的腿。直朝上或下射击时保留正背面和短促的肩身回推。三连发在真实的 0、100、200 毫秒出枪。|
| 风歌普通挥铃与主动突进 | 普通出手是近身短挥，主动有独立的起步、展开、扫过与回身轮廓。身体前送、后脚离地和月牙铃展开贯穿原有 160 毫秒突进，随后身体立起。 |
| 学员普攻与瞬发 | 普攻把书收在胸前再翻开。主动第一拍已经生效，随后的书页、张开的袖子和手臂走自己的一组图。收势回到持书站姿。 |
| 三人的连续收势 | 原普攻图格 16、17 像素完全相同。现在普攻动作结尾改用持枪、持铃或合书的准备格；三人的主动均使用各自的动作序列。人物没有新增回充等待，技能按钮继续读取原本的回充进度。 |
| 从左右受击与倒下 | 从右受击会朝左让开，从左受击会朝右让开。实际取到女武神两种相反的 8° 倾斜。普通闪烁最暗为 67%，学员减弱动态效果场次为 88%。在真实死亡入口分别核对了三人 13→14→15 三张倒地姿态，倒地后女武神放下枪、风铃落地、学员落坐收书，随后交给结算。|
| 追兵守点、突进与恢复 | 守点与蓄力压低轮身，冲刺伸脚，冲后收脚；寻路遇阻并且当帧没有位移时用直立形。近身与伤害仍读原本的碰撞区域。图格覆盖三个阶段，阻路分支另用状态回归检查。 |
| 发射器、干扰器、聚光队长、首领与弱点 | 正式发射器取格 3→4→5，队长 9→10→11，首领 12→13→14。首领的攻击控制器在弹飞行期间仍保留预备状态，所以本体另记一次真实出弹，首先展示发射，再落回静稳。低帧率若跨过作用时间，至少呈现一帧发射形。干扰器 6→7 与目标设施解除可涂状态同时发生。可打弱点连续取固定原画，方便瞄准。|

## 对照《乱涂！彩世界》

前两章 BOSS 实机的双拳落地片段里，上方双拳、地面两个圈、落下后的碎石可以沿时间对齐。用这个顺序复看本作，发射器与首领在紧闭时预告，真实弹体生成时展开，随后设备本体回稳。复核还发现过低帧率吞掉出弹姿态，以及首领开火后回到蓄力图的问题，两处已修。敌方接地锚点沿用原位置。[竞品 BOSS 实机](https://www.taptap.cn/moment/776073343404084700) · [上一轮动作对照](../2026-11-25-gap/motion.md)

上一轮 390 宽设备模拟中，追兵实画约为风歌身高的 31%。同一 CSS 比例下，本轮普通追兵的三种主姿态有效像素高 188–200 格内像素，乘以 71/256 的显示比例再计画布缩放，约 54–58 CSS 像素，相当于此前 93 像素人物的约 58%–62%。这个值按当前图格和显示尺寸换算。竞品报道里单次实画量得约 69%。当前两只红脚和外轮廓比旧版容易找，角色与追兵的高度差仍大于那张竞品截图；真实玩家的识别速度需要另外测。[双方原始尺寸证据](../2026-11-25-gap/art.md) · [竞品公测体验第 2 图](https://pic.kts.g.mi.com/f2209a7f7859168f3e4d7b6a46753edf5615817020868643455.png)

## 样本和可复查范围

- 通过正式名册、备战和第一章战斗采集 Chromium 移动视口 390×844 的 Canvas 画面。人物板第一列来自旧版，后五列为本轮，按人物世界坐标裁切。学员的上下行与主动启用浏览器减弱动态效果；受伤和倒地另取真实受伤入口的定向样本。相邻格所处街角和地图上色程度可以不同。
- 专项用游戏自己的建敌、压制和发弹入口，把敌人放在镜头里并保持存活。验证设备出手时同步记录图格、真实弹体和设施压制状态。测弱点时通过终局控制器记录一次已经躲开的攻击，使弱点开放。截图是正式场景中的受控案例。
