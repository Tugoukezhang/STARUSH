# STARUSH 三名出战角色与敌方动作复核

复核版本 `05f0a2d`。三张正式立绘对应的局内人物都已接上。有两处落差最明显。往屏幕上方跑时，角色还侧身朝右；一次攻击快收完时，最后两拍姿势相同。玩家一直在做的移动和普攻，优先级高于再做一套选人立绘。

## 实战证据

[角色原图与四向移动](motion-gait.webp) · [三人出手、受击与倒地逐拍](motion-beats.webp) · [按战斗时钟回放普通攻击](motion-contact-loop.webp) · [预警、干扰与可打弱点](motion-enemies.webp) · [队长与首领实际预警](arena-danger.webp)

从选人、第一章准备进入真实战斗。Chromium 模拟 390×844 触摸设备，Phaser 实际画布为 375×667。移动用方向键，主动技能用屏幕按钮。两轮共进六场。用于最终图版的三场分别记录女武神 162、风歌 89、学员 85 个渲染后画面；采样随浏览器负载变化，这些数量不能用来估算手机帧率。图版按角色实际位置裁切。左列原画、角色画面、攻击时钟分别来自原稿、画布和对应场次的战斗状态。动图以各自第一格为零点，从已录画面按战斗时钟取最近的上一帧，末尾停留方便观察。

为了让同一段动作可以再看一次，测试把一个真实杂兵放到可达位置，增加其血量，普攻和命中继续走原有逻辑；单独复查非致命与致命动作时，通过正常受伤入口触发，并把致命一击前的临时血量设为 1。敌方专项从实际建敌入口设置发射器、干扰器，令干扰器存活到压制设施；另在第一章终局控制器记录一次已躲开攻击后，观察开放的弱点。没有把这些选片当作三次自然通关或手机实测。

## 竞品里能看清哪几个动作

- 《乱涂！彩世界》前两章 BOSS 实机攻略的双拳片段，0.0–1.0 秒能同时看见上方的双拳与地面上两个圆圈，约 1.5 秒黑色碎石从圈的位置爆开。主体、地面落点和落下后的结果在同一幅画面里能对上。另一个片段 11.0–13.5 秒，人物移出黑圈，随后原圈附近出现灰色实体。可以直接检查“玩家离开后危险在哪”。这些片段里人物脚部很小，无法据此判断竞品用几张跑步图、是否做了特定骨骼或每拍用多久。[TapTap 前两章 BOSS 实机动图](https://www.taptap.cn/moment/776073343404084700)
- 项目资料库重看了负责人 v03、v16 九格采样。v03 有头发遮脸、口部和眼部拆开观察的画面，v16 有同一人物和多条时间轨。应用在验收里的是单看脸/武器/飘带各自的运动，以及停下后附件是否跟着回稳。当前可读材料为采样图，无法从中核实原片全部参数。[项目教程读取记录](../../TUTORIAL_REFERENCE_STATUS.md)

## 角色各小项

| 小项 | 这版实际表现、和玩家关系 | 制作顺序与肉眼验收 |
| --- | --- | --- |
| 三人局外与局内 | 红发护目镜、高马尾、白橙黑外套；绿发白花、青白裙与月牙铃；粉发白帽、蓝白校服与书。在走、打、受伤及失去行动时仍能靠这些特征认人。局内的风铃柄更长，书贴近手边，符合挥动和翻书需要。 | 保留身份。改动作后，把每位的原画与这四种状态并排，逐一核对头饰、配色、道具和拿法；无需重画已完成的女武神原设。 |
| 待机、起步、急停 | 步频由走过的距离推进；停下的三组样本都直接回到待机图格 12。待机另有眨眼和缓动。起步、刹停缺少可辨的重心转移，松手瞬间三人的身体都立即摆回准备姿势。 | P1。保留操作响应，补膝部压下、衣摆续摆或风铃晚半拍归位。连续做短按、急停、反向，角色位移当下响应，身体里还能读到停脚或收漂的一拍。 |
| 上下、左右与后撤 | 图版中女武神右、上、下都抽到同一图格 8；风歌右、上、下都抽到 10。学员上下也只在同一套六张侧身步态里换图格。向左能镜像，移动中瞄敌还会决定横向朝向。以身体单独判断向上赶路还是向下撤时，两者缺少信息。 | P1，先把一人的上行背影、下行前胸和侧移做全。连续上行→横移→倒退，保留射向敌人的道具角度。裁掉背景、只看身体，应能分出屏幕上下，再套到另两人。 |
| 女武神普通射击与三连射 | 普攻可见举枪、枪口作用、后坐。三连射按实际第 0、100、200 毫秒释放。射击动作和按键当帧对应。普通和主动的用力姿势很近，红发的碎发、枪托和肩膀在恢复段停成一张。正式单图集在移动射击开头会短暂换成整身发射姿势。 | P1。保留立即出弹，做专属肩部后坐、枪托归位和继续迈步的下身。关掉伤害字，在前进连射中逐发看枪口，三次都要回到枪上，脚步持续。 |
| 风歌普攻与主动 | 普攻先收风铃，再横摆，真实作用后进入收势；主动期间位移与扫击同步。两者都取同一套用力姿势。把人物从大风圈里裁出来，最容易看见的差别是她滑走了，多出来的身体动作较少。 | P1。让短挥靠手腕和铃摆，突进靠躯干前送、后脚跟进和飘带延迟。测试向左、向上和改向的突进，关掉风圈也能从连续姿势分出普通与主动。 |
| 学员普攻与主动 | 普攻有闭抱→翻书→收回的阶段，真实作用这一拍局内命中计数增加。主动是按下即生效的范围法术，打开的书和袖子仍取同一组攻击图格。贴近目标、亮色法术压过手部时，身体很难说明刚才是哪招。 | P1。保留瞬发，给主动一个更开放的手臂、书页和抬头轮廓，普通保持更小。看第一击时书和法术中心应在同侧；单位移开后，延迟效果应仍指向原判定点。 |
| 三人收势与技能回充 | 三套 256×256 角色格的第 16、17 格逐字节相同。运行时会按时把 16 换到 17，人物画面仍然停住。主动结束后身体随攻击、静止或移动状态恢复；技能与安可的回充进度由能力状态与 HUD 表示，局内没有要求人物持续摆一个回充动作。 | P1 修重复收势。给每人的第 17 格独立的枪托、铃锤或书页归位。对齐脚下，逐帧切 16→17→待机，检查武器方向、肩和衣摆是否连贯。回充与能否再按去按钮上验证，避免长时间让角色摆充能姿势。 |
| 受击、无敌闪烁 | 三人非致命命中后进入受击图组；角色缩身，红色染色，现有无敌闪烁一度让人物只剩约 30% 不透明度。受击姿态保持当前镜像，来自上方与侧方的冲击不会单独选不同受力方向。 | P1 先保住本人位置，再加强来向。固定同一姿势分别从左、右受击，闪烁最暗时要能追到头与鞋；躯干或武器至少一处往受力方向让开。 |
| 倒地、退出 | 临时致命一击触发正常死亡流程，各自停在图格 23，三人分别能看见坐倒或伏低。倒地共用第 18/19 格作前两拍，再走 22/23。角色身份和失败终点都清楚。 | 保留本轮倒地分流。P2 再做个性落地和道具余动。检查非致命一击可恢复，致命时留在地面的最后姿势再交给结算。 |
| 敌方杂兵、发射器、队长、首领、干扰器与弱点 | 六类有各自轮廓或功能标识。杂兵按位移摆动；本轮近身杂兵被打时读得到命中。发射器前摇保持同一张主体图，倾角低至约 −8°，释放转到约 +10°；线路、弹体承担了较多信息。队长在设施附近时身体与小怪聚在一起。首领从警戒到实弹时线路消退明显，本体轮廓变化小。干扰器从预备到压制时，实测设施已变为受压制，身体从约 +5° 的预备偏转转为轻微摇摆，仍为同一张敌人贴图。开放的独立弱点在镜头移到位后的连续约 1.03 秒的样本中保持同一静止轮廓，固定位置便于瞄准。 | P1 先做出手敌人。发射器张开出射口、首领给出压低→抬臂或换向→回稳的三个外形。锁线、躲避和伤害沿用真实判定。连续看蓄力和释放两帧，关闭文字、留线路及其余敌人，能指出谁在攻击、危险往哪走；干扰器开始压制时，应从它和设施之间读出连线生效；开放弱点继续保持稳定易瞄。 |

第 16/17 格的确认方法是分别按 6 列×4 行切开红、绿、蓝三张 motion.png，对原尺寸 RGBA 字节求摘要；三个图集里都仅出现这一对完全相同的格。正式角色选择取自 UserCastPresentation，敌方角色和动作取自 ActorPresentation、EnemyEnsembleMotion。先改方向与收势，再改三人主动轮廓和首领起手，验收时并排看同一输入、同一场地的前后两段。参照实现路径见 [角色表现](../../../game/src/systems/UserCastPresentation.mjs)、[三人主动时钟](../../../game/src/utils/publicPerformerAction.mjs)、[敌方主体动作](../../../game/src/systems/EnemyEnsembleMotion.mjs)。
