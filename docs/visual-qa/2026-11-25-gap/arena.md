# 战场、涂色与五章地图

第一章最先需要改的是危险线。聚光领舞锁定角色时，脚下的双线和女武神留下的粉墨挤在一起。到了露天剧场，首领本体甚至比主角还小，出招和收招主要靠一条线出现或消失来区分。两者直接影响玩家向哪边躲。安可侧卡的尺寸已合适，可以保留。

## 对照怎么读

我方版本 `05f0a2d`，Chromium 触屏模拟宽 390、高 844 CSS 像素，实际战区约 390×694，Phaser 画布 375×667，使用 Canvas 渲染。五章从巡演菜单、准备页进入，后四章使用独立测试存档解锁。每章上图是入场，下图把角色定位到北区第一处主设施附近，方便在相似位置看环境。北区样本保留当时的锁定状态。此次核对的是五章十个取景点，没有逐章打通。

三位成员的第一章特技从游戏按钮发出。为保证攻击真的命中，把游戏生成的普通追兵放到角色身边，同时记录目标血量和逐帧画面。图中毫秒是各自片段内的实际采样时刻，各人采到的帧数不同。队长、首领用游戏自己的生成与出招逻辑定点触发。镜头仍由游戏控制，首领样本前段可见它追到剧场，不能用这个移动量评价正常压轴切镜。剧场样本是未染色的地砖，染色后的首领线路仍需另拍。安可把能量补满后点真实按键，当次卡片从进场到离场另有 31 帧页面录像可供选帧。

《乱涂！彩世界》的两个参考各有用途。攻略的首领动图是连续战斗，按原比例缩到和我方同宽核对角色、预警、弹道。商店宣传片只看右侧实际游戏画幅，引用时间限于同一镜头。另一组实战截屏能看墨层、攻击接触位置与血条，无法量取动作时长。下列验收数字是建议的制作目标。[主线首领动图](https://www.taptap.cn/moment/776073343404084700) · [实战截屏](https://www.taptap.cn/moment/685113367278388669) · [商店影片，含《海蓝狂欢节》](https://www.taptap.cn/app/748842)

## 五章环境与玩法指向

竞品实战能验证两种设计。彩色设施在灰街和染色带之上仍有完整轮廓，玩家不读标签就能先找到一个物体；打地时以实际作用范围标出地面，玩家可以从形状决定站位。竞品样本没有我方的“串场站”“连续校音”或相同的五章路线。下表据本作规则检查这些机制有没有被画出来。[战斗截屏的街道与设施](https://www.taptap.cn/moment/685113367278388669) · [首领动图的地面范围](https://www.taptap.cn/moment/776073343404084700)

| 章节 | 实际看见什么，和玩法差在哪里 | 优先级与下一版验收 |
| --- | --- | --- |
| 1 星光初演 | 商铺的雨棚、唱片窗、暗灰车道、浅色路缘使旧街最像一处真实地点。北区口是斑马线与一截横栏。站在南口能辨出街道，却很难从远处把可互动的装卸门、要涂的灯箱和装饰门面区分开。 | P2。保留街道明暗。录一次从唱片店走向装卸门的转弯，在标签出现前能分别认出门铰与灯箱发光面，实走时触摸位置与画面对象一致。 |
| 2 霓虹街口 | 起点有弧形铺面、两边店面，设施仍用小符号指引；靠近建筑变淡后，左侧店面更难当成路线锚点。北区入口处显眼的是整条横隔板和一片灰广场。剧情规则要求先接两侧门灯再接中枢，同屏看不出依赖关系。 | P1。给试听店和咖啡亭各自可记的轮廓，短线只接向真正的中枢。首店完成、两店都完成各复拍一次，玩家能指向下一站以及已通电的一侧。 |
| 3 终场合奏 | 港湾入口能看到拱顶棚屋和右边舱房；到中段则以大片浅甲板、横运输栏和小设施为主，跟第五章的回港结构相近。规则里的“喷满后靠近双灯各校准一秒”需要站位，入场和北区首设施这两个镜头均没有展示帆顶双灯校准现场。 | P2。优先区分甲板拼缝、运输栏和可站区域；在两盏帆顶灯补拍“未喷满、可校准、正在校准、完成”。不读文字也能找到该靠近的灯脚，两灯可各自识别。 |
| 4 雨后返场 | 屋顶混凝土的破斑、板缝和圆形盖板把本章与港湾分开，材质强过其余章节。北区画面也同时出现红线、支路小字、提示手势，细碎底纹把校音及敌方信息夹在一起。此处拍到“驻点校音”的文字，尚未走完两区校音。 | P1。保留混凝土材质，把高频破斑压到边侧。近场校音圈、敌人危险线用不同轮廓；分别复核离开重置、串场供电后离开保留、被压制重置三种结果。 |
| 5 回港加演 | 重访同一港口符合剧情。同一取景能验证第五章多了沿地面折转的接线，第三章现场没有同样的连线。这是应保留的差异。第五章线条平直、转弯很多，接近栏杆与地砖接缝，静帧上起点、终点和流向仍主要依赖标签。 | P1。保留共用建筑，把线电流做成能读方向的节奏。录南区第一次接通、北区左右声部、由远端回流各一段，玩家可指出下一处可用设施、回流方向及哪扇门仍锁着。 |
