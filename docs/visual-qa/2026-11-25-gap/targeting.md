# 玩家瞄谁，追兵为什么停下

**最容易误读的是南口音箱。** 同一现场，任务箭头始终指着音箱。追兵靠近后，下一枪已经转向追兵，音箱上方的任务提示还在原处。手动点音箱才会出现第二种提示「集火 · 南口音箱」。在这次重叠站位，集火文字又压在角色上身。若只改一处，可以在自动换目标、即将出手时，给新目标脚下一个短促的指向标记。沿用原有任务箭头，出手后收掉标记。验收时遮住调试数值，看能否认对下一枪打哪边。[同场触控截图](targeting-focus.webp)

**竞品能对照到的部分。** 《乱涂！彩世界》海蓝狂欢节商店短片 00:05.50–00:08.25，中段同时有目标头顶的小红条、街边设施和短促命中亮光，亮光退去后还能找到原处。玩家录下的星条战车双拳 00:00.0–00:01.9，地面双圈与之后碎石落点对应。这两段允许我们比较「盯谁、打到哪、往哪躲」的画面提示。它们没有公开后台选敌顺序，也无法判断普通追兵何时改路。[逐段竞品记录与原链接](reference.md)

**复查条件。** 从当前工程的选人、巡演、出战入口进入 Chromium 390 × 844 触控会话。选设施时用真实场内对象，固定站位、暂停物理并暂缓自动开火，读取下一次选敌，随后用浏览器触屏点选和取消。两敌交错另开三场，执行了每位成员真实的首次普攻。绕墙场景仅停用自动射击，让普通追兵自行跑完。三组均通过，无页面脚本错误。这些固定场景验证能否读懂决策；常规游玩的遇见频率仍须另测。[历史改动记录](../../AI_AND_BUTTON_REVIEW_2026-11-25.md)
