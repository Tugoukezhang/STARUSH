# 从点开游戏到下一场，25 个模块的差距

核对版本为 `05f0a2d`。最需要先改的是角色串版。选择蔚蓝魔法师后，休息室画的是拿书的蓝白学园少女，台词却说「我想试试重锤的落点」。点旁边的「安可居所」，房间里站的是旧猫耳 Q 版，右侧头像点开写着「安可 · 重锤手」。返回后又回到蔚蓝魔法师。前三张是同一条实际路径。第四张来自独立从名册选择蔚蓝后进入的首章。唤起局内编排、实点「宽幅涂染」，技能说明又写「弹道、落点和重锤覆盖变宽」。蓝白角色的正式造型已经确认，可直接以负责人原图和现行战斗版为准。[四处实拍](systems-residence.webp) · [蓝白身份记录](../../BLUE_CHIBI_ALIGNMENT_2026-11-23.md)

## 容易被单页截图掩盖的地方

| 位置与重现方法 | 玩家实际看见什么 | 修改后的验收办法 |
| --- | --- | --- |
| 蓝白角色。主页 → 巡演后台 → 成员休息室 → 切换成员 → 蔚蓝魔法师 → 安可居所 → 右侧人物头像 → 左上返回 | 休息室台词、居所 Q 版、头像、展出的整身立绘一起串到旧版。居所是独立网页，常规 21 页检查不会走进去。 | 用同一个蓝白角色从名册、休息室、居所、编排走到实战，核人物名、衣帽、武器、台词和动作。若居所只服务一位角色，也按该角色的正式设计制作。 |
| 新号首次公演。主页直接按主操作，一直按默认按钮，直到角色能行动 | 前三次是「开始公演」「确认开演」「准备开演」，之后出现四句开场剧情。完整读完共点 7 次，选「跳过剧情」共 4 次。三个开演词实际通向配置、规则、故事，玩家仅凭按钮名难以预测自己的下一步。 | 保留换人和阅读剧情的选择。备战页写清开场后做什么，把十处设施和压轴的总说明同备战合并或移到首次触及对应目标时。比较新存档第一次能移动所需点击，同时复测剧情与跳过。 [四个连续实屏](systems-first-run.webp) |
| 五章通关档，从后台找练习，再到巡演找练习 | 后台入口的可访问名「练习目录」打开「练习广场」，只提供两段编排和开演目标。真正能开打一局的单站排练藏在「巡演 → 巡演资料 → 压轴排练 → 压轴排练室」。对照公开实图第 5 张，彩世界把可玩的模式做成可辨认的目录卡。 | 在同一处让人读到「开始单站练习」与「开场前编排」，共用一个目的地；从首页用两次选择即可辨认哪一项会开打。锁定时保留真实的通关门槛。[本作三处入口](systems-practice.webp) · [竞品玩法目录](https://www.taptap.cn/moment/685538921035073313) |
| 成员训练。在五章档确认风歌出战，再点开演前确认 → 成员训练 → 训练 | 练习笔记 27→24，阶位 1→2，「当前涂染增益」0%→10%。按规则，无配件时此次提升的是主动行动涂染威力，攻击涂染范围和充能倍率没有变。成长规划里才把这三项拆开。玩家在付款这一层读不到收益范围。 | 付款旁直接显示「主动涂染威力 0% → +10%」，成长规划、装备详情、局内技能使用同一个名词；确认仍只扣 3 笔记。[数值来源](../../../game/src/utils/publicPreparation.mjs) |
| 回港加演的「速演挑战」。从「公演企划 → 目标详情」和「练习广场 → 开演目标」各走一次 | 前一处是预览，一行写「可设定」，还要点「设定目标」。后一处直接选；同一目标先显示「预选」，点「确认目标并准备」才把 40.000 秒条件带入备战。它是挑战自己的纪录，企划页没有领日常奖励的流程。 | 企划页让任务名和「设置本场目标」成组。条件和「已用于下一场」分别只显示一次；目标判定仍以当前成员、章节和实测成绩为准。 |
| 进入三站连演或进入场馆 | 连演详情明确写生命继承、刷新不保留、没有巡演奖励，目录一级主要写「三站压轴 · 生命继承」。场馆实点「编辑排班 → 翡翠风歌 → 保存排班 → 确认筹备」，结果显示「翡翠风歌 · 舞台试音 · 已筹备」。两处都需要在做决定前看懂收益边界。 | 开打旁直接写「不发巡演奖励」，场馆筹备后展示人、节目及完成状态。保留两套独立的保存逻辑。 |

## 逐模块对应

参考的图序按一测文章正文图片从 1 数。第 1 张可见主页，第 5 张可见玩法目录，第 7 张为带收获按钮的资源面板，第 10 张有挑战对手和奖励进度，第 14、15 张为两种场地图，第 36 张是货币总览，第 37、39、40 张分别可见单角色、属性和配装。第 7 张的领取按钮只能证明它所在面板支持领取；本作首通的自动入账按本作检查。下表的「同类」表示能直接对比画面中的任务，「借鉴」只借可见的表现方式，「自身」表示列出的参考没证明竞品有同一功能。[一测实图与正文](https://www.taptap.cn/moment/685538921035073313) · [公开涂色演示](https://www.taptap.cn/moment/685113367278388669)

| 登记模块 | 对照范围 | 本作现状、差距或验收重点 |
| --- | --- | --- |
| 01 全局导航 | 同类，图 1、5 | 首页主操作突出，二级路由仍有语义冲突。「练习广场」找不到开练，玩家要去巡演资料找「压轴排练」。把开始战斗、查资料、整理方案三个目的用不同动词标出来。 |
| 02 界面与演出 | 借鉴，图 2、7 的信息层次 | 首次一路出现三枚近义开演键；逐屏按钮足够大仍消除不了重复确认。局内安可的弹窗按独立战斗实画验收。 |
| 03 本地存档 | 自身 | 服务页新号显示「暂无已保存公演」，通关档显示本机进度。完整本机备份和账号云同步要用明确的保存位置区分。 |
| 04 声音与设置 | 自身 | 主页齿轮的可访问名是「声音与公演规则」，后台服务中的入口是「声音与演出设置」。两条入口进入同一会话设置，建议统一入口名称。实体扬声器未试听。 |
| 05 巡演章节 | 同类，图 14、15 可比地标、未解锁分支 | 新号五站展示下一站与逐章锁定条件；首通后「下一站 · 霓虹街口」打开正确的新章备战。选站地图、场地简报、实战第一屏应让人认出同一个地标。 |
| 06 剧情与档案 | 自身 | 从巡演资料打开演出档案，点单章，再点「开场」能播放台词；开场、途中和章尾有相位，但首章三项共同叫「旧商街的第一排」。可用每段的一句事件区别剧情。五章合成档的「未读」不会被通关自动覆盖。 |
| 07 遭遇与压轴 | 借鉴，图 10 的首领与奖励目标 | 首章简报有「恢复十处演出设施，再完成露天压轴」及三步，但首屏要同时理解设施、选线、压轴。把当前可接通的首设施和最终压轴分两次教。此次从开场走入实战；结算事件抽查不能衡量十处设施的难度或 AI 胜率。 |
| 08 演出结算 | 借鉴，图 7 的收获层次，非同一奖励流程 | 女武神首通实显练习笔记 +6、扩幅导流器、随行喷头。「下一站」的确转到第二站，配件仍未装备。保留自动入账，首通页用实物图、用途、去处说明为何要点配件。 |
| 09 人物战斗 | 同类，公开涂色实战只作画面依据 | 正式战斗每次出战一人。首局能真实触放女武神技能；后台文案和居所美术接回旧蓝白身份。跨页使用同一角色来源，补上局内编排选项的角色用语验收。 |
| 10 局内编排 | 借鉴，图 40 的当前配装与可选项 | 练习广场显示女武神两段 12 种组合。点「预选方案并准备」，备战会列出「宽幅涂染 · 回响追加」。练习方案、局内选定、永久装备属三种作用时间，应让每层都说清生效时点。 |
| 11 世界涂染 | 同类，公开战场 | 首次规则写「街面随攻击显色」「演出设施涂满后才能接通」。玩家需要同时分辨地上已经有颜色、设施接通了多少、这一站是否恢复；不能以地面粒子数量判断规则是否清楚。 |
| 12 成员管理 | 同类，图 37 的成员主位 | 后台成员介绍点风歌再点「查看成员阵容」，名册先显示「候选出战成员」，单独确认才生效。正式部署一人，改入口为「查看成员／设为出战」即可避免误会有多个站位。 |
| 13 训练与成长 | 同类，图 37、39 的对象和属性 | 阶位与笔记实际变动正确，但训练页只叫「涂染增益」。让升级收益聚焦于主动行动威力，与详细成长规划使用同一名称。 |
| 14 装备与配装 | 同类，图 40 | 新号「已拥有 0、适用 5、全部 7」，五章女武神档变为「已拥有 5、适用 5、全部 7」。两组 5 含义不同，兼容筛选仍应独立展示持有／缺少与来源；比较属性须指出影响普攻还是主动。 |
| 15 关系与个人故事 | 自身 | 正式休息室答风歌「从稳稳的一步开始」，相处记录保存 1 次及原回答。蓝白欢迎词和独立居所串版严重；优先修此链，再扩话题。 |
| 16 排练与连演 | 借鉴，图 5、10 的模式入口 | 五章档能进单站和三站准备。后者规则清楚写了生命跨站、行动充能重置、重新开局和存档边界；把本轮的记录和奖励规则移到开演键旁。 |
| 17 附加玩法 | 借鉴，图 5 的功能分组 | 登记为「附加玩法」，正式内容是查看编排与设定目标的练习广场。两个入口可用；这里没有第三个可以开打的模式，别用新增游戏宣传图补数量。 |
| 18 活动与专题 | 借鉴，图 5 的目录，图 16 的分项进度 | 正式「公演企划」展示所选章节和五站进度。目标详情里也能转到本场目标。叫「本期活动」或加限时红点会让用户误以为有独立奖励。 |
| 19 成员获取 | 借鉴，图 37 的人物资料 | 登记名对应到「成员介绍」。三人由开局提供，切换介绍不会直接换出战成员；本作没有为本页登记招募规则，人物信息和选人入口比抽取按钮有用。 |
| 20 个人演出目标 | 借鉴，图 10、16 的条件展示 | 新号可选 1/3。五章实测成绩档可选 3/3，明确显示少于 2 次受击、短于 40 秒等个人目标。简化「可选／预选／已确认」重复词，让玩家看清本次提交的是哪一项。 |
| 21 现有资源政策 | 借鉴，图 7、36 的物品与数量 | 首通给 6 笔记，同一个系统训练 1→2 阶花 3。新号余额 0 时主屏只剩一个计数，训练显示还差 3；可以用一句真实来源连起「赢一场 → 有笔记 → 下次提升主动技能」。 |
| 22 场馆经营 | 自身 | 舞台、排练室、休息室各有排班与筹备。选择成员、保存排班、确认筹备是三个不同状态；此处只改变房间记录，收获展示应围绕节目和当班成员，避免暗示战力或周期收入。 |
| 23 账号与云存档 | 自身，规划 | 「设置与存档 → 服务状态」明确显示未接入。当前本机备份是真入口。没有账号、云槽位的实机交互可对比。 |
| 24 社交与联机 | 自身，规划 | 同一窗可见「好友与联机」及未接入原因。休息室是单机角色互动；不能将它计入好友、队伍或多人对局。 |
| 25 平台服务接入 | 自身，规划 | 服务窗口明示平台账号和支付未配置。竞品商业页面只能用来看按钮层级，不宜照搬领取、付费、倒计时等会产生交易预期的控件。 |

## 范围和复核

- 产品登记工具输出 25 模块、22 个有运行逻辑、3 个待接服务、21 个菜单页、3 种模式。路由目录有 5 个根项，实际首页底栏显出 4 项，演出档案可以从巡演资料进入。局内弹窗和独立居所另计。[模块登记](../../../game/src/utils/publicProductModules.mjs) · [路由登记](../../../game/src/utils/publicShellNavigation.mjs)
- 本轮 Chromium 390×844 依次读取全部 21 页在新号和五章档的内容与可用操作，共 42 个菜单状态。读全页用 QA 定位；上述首战、第二章入口、训练、选人、编排资料库、目标、挑战目录、档案、聊天、场馆与居所从可见控件进入。正式画面来自当前游戏的 Vite 入口；特地用软件 WebGL 打开居所。
- 五章档用同一套正式记录接口写入五章通关，每章 40 秒、受击 2 次。首战独立用空存档开局并触放技能，通过游戏自身的胜利事件唤起结算，再点「下一站」确认开演进入第二章。蓝白局内编排用游戏自己的编排事件唤起，选项详情由真实点击读出。此次未从头手打完整五章，也未把测试成绩作为玩家难度数据。旧版的多视口记录可作补充。[既有设备检查](../2026-11-25-setdesign/audit/README.md)
