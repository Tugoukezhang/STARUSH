# 红发女武神战斗 Q 版：制作与验收

状态：素材和接入已完成；最终浏览器重开与远端备份核对中。角色来源为负责人确认的 `01-美术/owner-originals/橙白黑赛博战术女武神.png`，本轮制作对应的战斗 Q 版，不把它记作历史立绘模型恢复。

## 制作前验收条件

- 橙红高马尾、护目镜、白橙黑服装、不对称衣摆与战术武器保持原图身份；手机尺寸可辨认。
- 主动作图集覆盖待机、移动、射击/技能、受击与倒地；全部使用同一新设计，动作切换不回旧猫耳形象。
- 脚底与地面相接，移动用实际走过的距离控制步频；射击和技能跟随实际动作时钟，暂停、恢复、退出和重开清理正确。
- 对应成员的立绘、头像、结果页和武器图标检查一致；已完成的旧角色模型历史不重算，另外两名角色的待办明确保留。
- 源图、生成提示、图集/帧注册、接入代码及测试入库；浏览器真实入口检查后推送并取回核验。
