# 恢复资料，不是完整工作树

这里保存从原制作记录中恢复的项目文件，供逐模块接续。它们来自不同时间，不能整包覆盖 `game/`。当前可运行入口是仓库根目录的 `game/`。

- `historical-files/`：按项目路径保存的历史候选，包括美术工具、运行代码、测试和制作报告。
- `additional-versions/`：同一路径的补充历史版本，按 SHA-256 分开保存；版本差异有意保留。
- `production-queue.historical.txt`：原队列可见行。相同编号可能出现多条历史状态，不代表本次全部重新验收。
- `manifest.json`：每份文件的路径、字节数、校验值和来源类别。只有 `matches_recorded_historical_hash: true` 表示本版本还与原记录中的哈希吻合；其他校验值只证明当前副本保存完整。
- 三张用户正式 PNG 保存在 `../01-美术/owner-originals/`，也列入校验清单。

原聊天和工具日志保存在独立恢复档案，没有提交到本公开仓库。此目录里的历史制作说明不覆盖根目录现行 `AGENTS.md` 和 `docs/CURRENT_CLOUD_HANDOFF.md`。历史 AGENTS 已改名为普通文本，避免当成现行指令。

接续时先检查某一模块的依赖和不同历史版本，再把经核对的文件应用到正式目录，完成该模块的测试、实际画面检查、提交和远端核对。恢复工作不增加 Q 队列完成数量。
