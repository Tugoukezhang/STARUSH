# Q47：第三章港湾空间与校音辨识

## B379实施前验收条件

查看既有原创甲板图后确认水陆分界已有连续边缘，不重复加假障碍或导航路线。改进实际设备舱、调音亭和舞台立面与甲板的接地关系，按第三章已注册可见图形底边绘制克制的静态接触影，排除可收起运输栏；不改海水、建筑碰撞和设施位置。

第三章校音圈在彩色涂染上增加深色底描边，保留真实半径、四个刻度、进度弧与压制色，不伪造范围或校音进度。地面圈/设施标签使用港湾建筑真实边界，普通目标名与引导去重，关键校音/遮挡/压制/锁定说明继续存在。只作用于第三章；第四、第五章共享设施不可顺带更改。低特效档保留所有玩法读数，新增接地为静态层，无帧动画/新粒子。

验收包含注册锚点、碰撞不变、校音几何/状态、章节隔离与销毁、前三章名称回归；实际第三章普通输入到北区并完成真实校音，明确只解锁前两章这一前置。检查全/低特效、真实涂染/遮挡、暂停/存档与控制台，生产构建后验证最终入口和移动。受控绘图对照单列，不当自然完成或通关证据。未完成检查保留断点，不以此文档替代交付。
