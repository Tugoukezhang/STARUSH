# Q58：失败恢复与难度曲线整改

## 编码前发现与验收条件

自然样本B388重锤第四章（雨后返场）在8/10设施生命耗尽；同批其他路线可通过，不能用单次随机失败断言必须削弱敌人。检查实际结算链发现：局内暂停能读取本区主设施/待校准数，finish没有捕获这些字段，结果页丢失上下文，遇到已涂满但需校准/本区串场阻塞时只提示继续主设施。雨后1.5秒连续校准/完成本区两站储备后的保留规则也没有进入实际进度建议。

实施：将真实分区与待校准状态在结束清理前冻结到本场结果上下文（不作为跨局进度、不写新的奖励账本）；局内和失败复盘共用读取。雨后提示严格区分本区已储备与未储备，压制仍重置；只在真实待校准站存在时显示，不凭设施数猜测。明确“重试本站”重置设施/串场/局内编排、使用最新已保存训练/配件、不扣练习笔记；“继续公演”才恢复当前存档生命/剩余时间，不借恢复免费治疗。

验证真实结束→清理→复盘、错误/缺失上下文、胜利/压轴优先、重复结束/保存不增奖励、重试新runId和归零与当前断点恢复的区别。自然失败后点击重试，检查档案不重发奖励；三角色正常路径/暂停建议、小屏失败界面和控制台，相关测试与生产构建。特定校准状态可用受控Phaser夹具，必须明确不宣称自然通关。Q58不凭文档标完成，不无依据改生命/敌人数值。
