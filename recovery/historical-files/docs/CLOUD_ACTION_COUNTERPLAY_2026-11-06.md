# Q56：技能与章节机制联动

## 实施前验收条件

交付两类新的真实联动：①技能的实际涂染命中尚存活的蓄势/突进追兵时，将其送入现有720ms恢复，停止速度和捕获预告；普通攻击不获得此效果，已死亡目标不重复计入。②技能真实释放覆盖的区域可消除普通散弹，须在同一合法地形可见区域，不能清除首领声浪、地面落击、折返弹或替代压轴读招。

仅正式公演三角色、真实接受的行动sequence生效；沿用100技能消耗、真实涂染范围与既有弹体销毁owner。不新增免费生命、充能或掉落；解除突进不算击杀、不重复收取奖励。多拍/多帧释放以存活弹体和现有追兵状态保证一次性；暂停、死亡、旧action回调和读档不能重放。恢复状态沿现有检查点保存，不迁移旧规则正在战斗的存档。

验收包括真实action→paint收据→机制owner契约、普通攻击对照、挡墙/范围/伪造目标/压轴保护/暂停/销毁/恢复，至少三角色正常输入实跑观察两类交互，并验证不用技能仍可完成。受控真实浏览器夹具可补特定状态/截图，须明确不当自然通关。规则升级后生产构建、三角色实际操作、旧档/新档及控制台检查。未验收不标完成。
