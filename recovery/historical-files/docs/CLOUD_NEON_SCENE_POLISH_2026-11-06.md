# Q46：第二章光色与设施辨识

## B378实施前验收条件

在现有原创第二章场景和实际涂染上增加局部设施发光落地关系：已获得的设施涂染进度才产生克制的地面反射，关闭/锁定/压制不显示通电亮光，完成态读取真实角色色。发光与底座局限在设施周围，不覆盖中央战斗通道或替代弹路、敌人、角色反馈；使用普通混合、不全屏泛光、不闪烁。原建筑、碰撞、设施坐标、伤害、奖励、存档保持。只接入第二章，不串入共享场景的后续章节。

每场最多一个Graphics，只有进度/颜色/状态变化才重建，暂停无时序动画，销毁清理；提供量化绘图预算但不宣称手机GPU性能。测试实际累计进度、锁定/压制/恢复/完成状态、章节隔离、缓存与销毁、地面涂染及原地图通达性。真实浏览器用明确标注的“只解锁第二章前置”档案进入，正常输入完成南口→街口→北区路线，检查不同角色/弹路对比、设施实际状态和保存；不得注入当场生命、位置、进度或胜利。受控状态对照与自然路线分开记录。最终生产构建和原生入场/行走/暂停、控制台通过才验收Q46。

继续参照Q45已读取的W3C非文本对比原则及仓库场景美术规范；沿用原创音柱、建筑和地面，改善灯光在地面的落点与层级，不复制参考资产。
