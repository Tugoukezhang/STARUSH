# Q80 绿色眼口表情候选

已制作3张隐藏区补绘，10个独立眼部PNG（左右眼白/虹膜/高光/上下睑），83层OpenRaster候选和浏览器检查器。原始Q78源与Q79头脸模型保持独立。

尚未验收：虹膜与原眼内轮廓的中性重组仍需精修；口内补绘尚未拆分；没有眨眼、九向注视、微笑参数，也未做与头部极值组合验收。不能把source-browser控制通过当表情完成。

`build-eye-source.py`只定义SVG选区/UV和调用Inkscape导出，图像补绘来自image_gen；来源和注册见provenance.json。首次候选虹膜越界/旧虹膜残留、后续亮度遮罩抹睫毛的失败证据保存在仓外。当前显式以原眼图alpha作为遮罩，避免黑睫毛被误删。
